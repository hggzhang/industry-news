## 二、本周重要事件

### 1. [重大] [大模型] 阿里发布迄今最大规模推理模型 Qwen3-Max-Thinking

- **发生了什么：** 1 月 26 日，阿里巴巴正式发布千问旗舰推理模型 Qwen3-Max-Thinking。该模型参数量超过万亿，预训练数据规模达 36T tokens，并通过引入自适应工具调用与测试时扩展（test-time scaling）两项核心技术，显著提升了推理性能与原生 Agent 工具调用能力。
- **为什么重要：** 这是中国厂商在旗舰推理模型上对 OpenAI、Google 最新一代模型的正面回应。自适应工具调用意味着模型可以在推理过程中自主决定何时调用外部工具，是原生 Agent 能力的关键指标；该发布也拉开了国内厂商春节档密集上新（百度、月之暗面、阶跃星辰、快手随后跟进）的序幕。
- **关键细节：** 官方口径强调两项技术创新：一是自适应工具调用，二是测试时扩展。媒体将其定位为"阿里迄今最大规模推理模型"。同期策略周报将其列为本周 AI 行业第一事件。
- **来源：** http://www.chinanews.com.cn/m/cj/2026/02-24/10575807.shtml ；https://pdf.dfcfw.com/pdf/H3_AP202602011819060817_1.pdf

### 2. [重大] [大模型/开源] 月之暗面开源 Kimi K2.5：1T 参数 MoE，开源编程榜第一

- **发生了什么：** 1 月 27 日，月之暗面（Moonshot AI）发布并开源 Kimi K2.5。这是一个 1T 参数的 MoE 模型，使用约 15T 图文混合 token 训练，支持多模态。其在 LMArena 开源模型编程榜排名第一，SWE-bench 得分 76.8%，Humanity's Last Exam 得分 50.2%，超过 Claude Opus 4.5 的该项分数。模型还引入 Agent Swarm 能力，可编排最多 100 个并行子代理、执行约 1500 次工具调用，速度较单代理提升约 4.5 倍。
- **为什么重要：** 定价上 Kimi K2.5 每百万 token 输入 0.60 美元、输出 2.50 美元，约为 Opus 价格的 10%，加上开放权重（约 595GB，已上传 Hugging Face），它把"接近第一梯队的编程与 Agent 能力"直接变成了开源社区可自托管的选项，被评价为将开源阵营与头部实验室的差距缩小到 9 个月左右。
- **关键细节：** 开放权重；支持视觉与文本混合输入；Agent Swarm 多代理编排是本次发布最大的差异化卖点；博客地址为 kimi.ai/blog/kimi-k2-5。
- **来源：** https://kimi.ai/blog/kimi-k2-5 ；https://www.updatic.com/kimi-k2-5-open-source-model-8-groundbreaking-ai-advances-for-2026/ ；https://www.ai-insight-solutions.com/blog/january-2026-ai-engineering-roundup/

### 3. [重大] [AI 产品/Agent] Google 大改 Chrome：Gemini 常驻侧边栏并支持 Auto Browse 自动浏览

- **发生了什么：** 1 月 28 日，Google 发布 Gemini in Chrome 的重大改版：AI 助手以常驻侧边栏形式出现在活动标签页旁，无需切换标签；旗舰功能 Auto Browse 可执行跨站多步骤任务（订机票、找房、比价、填表），并在购买、发送消息等敏感操作前向用户请求确认。同时内置 Nano Banana 浏览器内图像变换，并接入 Gmail、Calendar、YouTube、Maps、Shopping、Flights 等应用。
- **为什么重要：** 浏览器是全球用户最大的日常入口，把"代理式浏览"做成浏览器原生功能，意味着 Agent 第一次以默认形态触达亿级普通用户，而不只是开发者工具。该功能与美国 AI Pro、Ultra 订阅绑定，也展示了 Google 用订阅分层消化 Agent 成本的商业思路。
- **关键细节：** Auto Browse 与 Universal Commerce Protocol（UCP）配套，UCP 是与 Shopify、Etsy、Wayfair、Target 等共同开发的开放购物协议；1 月 27 日 Google 还向 Gemini 3 Flash API 加入了 Agentic Vision，让图像理解变成"视觉推理 + 代码执行"的迭代过程；同日 Google AI Plus 以每月 7.99 美元进入包括美国在内的 35 个国家。

## 三、本周行业变化总结

本周的结构性变化有三条主线。第一，入口之争从"聊天应用"转移到"你已经在用的软件"：Chrome 侧边栏、Claude 对话内的 SaaS 界面、LaTeX 编辑器里的 GPT-5.2，三家头部公司不约而同把 AI 塞进既有工作流，独立 App 的吸引力在下降。第二，中国开源阵营完成了一次质量与价格的双重突袭：Kimi K2.5 以约 10% 的价格逼近闭源旗舰的编程与 Agent 能力，叠加 Qwen 全家桶（Max-Thinking、ASR、Coder-Next）与 DeepSeek-OCR 2，开源可选性显著改善。第三，资本与算力进入"千亿级常态化"：OpenAI 千亿融资洽谈、Meta 1350 亿美元资本开支指引、微软自研芯片，三者共同说明竞争壁垒正在从模型本身转向资金与基础设施。

## 四、本周趋势分析

1. **Agent 的"界面标准化"开始发生。** MCP Apps 让工具返回可交互 UI，Chrome Auto Browse 让浏览器变成执行器，Agent 从"输出文本建议"进化为"直接完成操作"，敏感动作的人工确认成为标配。预计接下来数周会有更多 SaaS 跟进 MCP Apps。
2. **多代理编排成为开源模型的差异化战场。** Kimi K2.5 的 Agent Swarm（100 并行子代理）把"模型能否指挥代理集群"变成新的比拼维度，测试时扩展与并行子代理的结合可能定义下一代推理模型的产品形态。
3. **推理成本竞赛从模型层下沉到芯片层。** Maia 200 主打 FP4 推理性价比，Grok Imagine 用每分钟 4.2 美元重定价视频生成，"每美元 token/秒数"正成为比榜单分数更硬的指标。
4. **资本开支与营收增长同时刷新纪录，但市场开始定价风险。** 微软大额市值回撤说明投资者对"AI 投入回报周期"的耐心在下降，融资与开支的可持续性将成为下阶段主线。
