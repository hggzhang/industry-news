## 二、本周重要事件

### 1. [重大] [政策/监管] 白宫发布《美国 AI 行动计划》并签署系列行政令
- **发生了什么：** 7 月 23 日，白宫发布《赢得竞赛：美国 AI 行动计划》（Winning the Race: America's AI Action Plan），提出 90 余项联邦政策行动，围绕快速创新、基建扩张与国际领导权三大支柱推进美国 AI 主导地位。同日特朗普签署加速数据中心联邦审批的行政令，要求商务部为合格项目提供贷款、补助与税收支持；随后又签署"促进美国 AI 技术栈出口"与"防止联邦政府采用 woke AI"两项行政令。
- **为什么重要：** 这是特朗普政府 AI 政策从 1 月行政令框架落地为完整执行文件的标志：放松监管、把数据中心当国家基建、向盟友输出"美国全栈 AI 包"，同时以行政手段干预模型价值取向。它直接定义了未来两年美国 AI 产业与监管的边界，也加剧与欧盟规则路线的分裂。
- **关键细节：** 行动计划强调"创新优先、去监管"，涵盖能源、芯片、开源与劳动力政策；数据中心行政令把"快速建设"列为国家优先事项；出口行政令将 AI 技术栈输出上升为 coordinated national effort；"反 woke AI"令要求联邦采购的 AI 不得内置意识形态偏见。
- **来源：** https://www.whitehouse.gov/articles/2025/07/white-house-unveils-americas-ai-action-plan/ 、https://www.whitehouse.gov/fact-sheets/2025/07/fact-sheet-pre 、https://www.whitehouse.gov/presidential-actions/2025/07/promoting-the-export-of-the-american-ai-technology-stack/ 、https://www.ai.gov/action-plan

### 2. [重大] [基建/算力] OpenAI 与 Oracle 宣布 Stargate 新增 4.5 吉瓦数据中心协议
- **发生了什么：** 7 月 22 日，OpenAI 与 Oracle 宣布达成协议，在美国开发额外 4.5 吉瓦的 Stargate 数据中心容量。官方表述称该投资将创造就业、加速美国再工业化并推进美国 AI 领先地位。
- **为什么重要：** 4.5 吉瓦相当于数座大型核电站的供电规模，单家厂商的算力承诺已进入"能源工程"量级；结合本周白宫数据中心审批松绑，"算力=电力=土建"的产业逻辑被彻底坐实，供应链（电力设备、冷却、建设）与资本市场随之重估。
- **关键细节：** 该协议是 Stargate 计划（与软银、甲骨文等共建的千亿美元级项目）的阶段性扩容；同周摩根大通预测 OpenAI 未来四年将烧掉约 460 亿美元、盈利节点推迟至 2029 年，资本开支与回报周期的争论同步升温。
- **来源：** https://openai.com/index/stargate-advances-with-partnership-with-oracle 、http://files.chinaaet.com/files/2025-08-18/20250818145745-70351.pdf

### 3. [重大] [开源/编程工具] 阿里开源 Qwen3-Coder，登顶全球开源编程模型
- **发生了什么：** 7 月 22 日至 23 日，阿里巴巴发布并开源代理式编程大模型 Qwen3-Coder，首发旗舰 Qwen3-Coder-480B-A35B-Instruct：总参数 480B、激活 35B 的 MoE 架构，原生支持 256K token 上下文、经 YaRN 可扩展至 1M。官方称其编程能力登顶开源模型阵营、比肩全球最强闭源编程模型，在 SWE-bench Verified 等代理式编程基准上表现领先。阿里云同步将其免费不限量接入通义灵码。
- **为什么重要：** 编程是 Agent 商业化最先跑通的场景，中国厂商以最大尺寸开源模型直接对标 Claude/GPT 旗舰，把"代理式编程"的竞争从闭源 API 拉入开源生态；对全球开发者意味着高质量编程 Agent 底座从此有免费可自部署选项。
- **关键细节：** 模型强调 Agentic Coding、Agentic Browser-Use、Agentic Tool-Use 三类代理能力；发布当日即被产业周报收录为"登顶全球开源模型榜首"；通义灵码下载量超千万级，是国内用户量最大的编程辅助工具之一。
- **来源：** https://qwenlm.github.io/zh/blog/qwen3-coder/ 、https://www.alibabacloud.com/en/press-room/alibaba-unveils-cutting-edge-ai-coding-model-qwen3 、https://www.alibabagroup.com/document-1886524500057522176

### 4. [重要] [编程工具/Agent] Anthropic 推出 Claude Code 网页版研究预览
- **发生了什么：** 本周 Anthropic 宣布 Claude Code 进入网页端：开发者可直接在浏览器中分配多项编码任务，任务运行在 Anthropic 托管的云端环境，支持并行执行、自动修复 Bug、日常维护与自动生成 Pull Request，面向 Claude Pro 与 Max 用户开放研究预览。
- **为什么重要：** Claude Code 是 2025 年最具影响力的终端编程 Agent，网页化把它从"工程师的 CLI"变成"任何开发者（及非工程师）的云端任务队列"，与 OpenAI Codex 类云端代理正面相遇；"多任务并行 + 托管环境"正在成为编程 Agent 的新产品形态。
- **关键细节：** 网页版可连接 GitHub 仓库、实时管理与监控任务；同期 Anthropic 披露用"自主 AI 审计员智能体"对 Claude 等强模型做安全审计（7 月 25 日报道），把 Agent 同时用于生产力与安全性。
- **来源：** https://www.m360.cn/article/info/8196 、https://www.artificialintelligence-news.com/news/anthropic-deploys-ai-agents-audit-models-for-safety/

### 5. [重要] [大模型] Google 发布 Gemini 2.5 Flash-Lite 稳定版，主打"每美元智能"
- **发生了什么：** 7 月 22 日，Google 发布 Gemini 2.5 Flash-Lite 稳定版，定位为其最便宜、最快的推理模型（输入价格约每百万 token 0.10 美元级别），面向大规模 API 工作负载，宣传口径从"更强"转向"intelligence per dollar"（每美元智能）。
- **为什么重要：** 旗舰模型能力趋同后，价格与吞吐成为 2025 年夏天的主战场；Flash-Lite 稳定版把"推理模型平价化"推向 API 开发者市场，直接冲击 OpenAI mini 系列与开源小模型的高性价比生态位。
- **关键细节：** 同周 Google DeepMind 还于 7 月 21 日宣布 Gemini 2.5 Deep Think 在 2025 年 IMO 解出 6 题中 5 题、获 35 分达到金牌标准并获官方认证，"高端冲金牌、低端冲价格"的哑铃策略成型。
- **来源：** https://www.artificialintelligence-news.com/news/googles-newest-gemini-2-5-model-aims-intelligence-per-dollar/ 、http://www.news.cn/20250801/39b6c7115535453897e75ee37e7709eb/c.html

### 6. [重要] [政策/政府合作] OpenAI 与英国政府宣布战略伙伴关系
- **发生了什么：** 7 月 21 日，OpenAI 与英国政府宣布战略伙伴协议，目标是加速 AI 在英国的采用、推动经济增长并提升公共服务水平，支持英国构建繁荣的 AI 生态。

- **关键细节：** 协议覆盖 AI 采用、经济增长与公共服务三大方向；同周美国"AI 技术栈出口"行政令也显示各国政府都在把前沿模型厂商纳入国家出口与外交工具。

### 7. [一般] [研究/架构] 新加坡初创 Sapient 发布"比 LLM 快 100 倍"的分层推理架构 HRM
- **发生了什么：** 7 月 24 日至 25 日，新加坡 AI 初创公司 Sapient Intelligence 发布分层推理模型（Hierarchical Reasoning Model，HRM），称其受大脑"快慢双系统"启发，仅用约 1000 个训练样例即可在复杂推理任务上追平甚至大幅超越 LLM，推理速度快达百倍级。
- **为什么重要：** 在"堆参数堆数据"的主流路线之外，HRM 代表小样本、小模型、专用架构的替代叙事，若持续验证将对边缘设备与低成本推理市场产生冲击；本周也引发开源社区大规模复现与讨论。
- **关键细节：** VentureBeat 报道其模型规模显著小于 LLM 且数据效率极高；同期 Anthropic 研究（arXiv 2507.14417）指出"思考更长反而可能降低准确率"（分心、过拟合、虚假相关），两条研究线索共同质疑"无限拉长推理链"的路线。
- **来源：** https://venturebeat.com/ai/new-ai-architecture-delivers-100x-faster-reasoning-than-llms-with-just-1000-training-examples/ 、https://arxiv.org/pdf/2507.14417

### 8. [一般] [安全/法律] Altman 警告：用 ChatGPT 做心理治疗不受法律保密保护
- **发生了什么：** 7 月 25 日，OpenAI CEO Sam Altman 公开回应 AI 与法律体系衔接问题时警告：目前不存在针对用户与 AI 对话的法律保密特权，把 ChatGPT 当"治疗师"使用的敏感内容不受医患式保密保护。
- **为什么重要：** 数亿人已在向模型倾诉隐私，而法律框架尚未跟上；这一表态把"AI 对话数据权"推入公共议程，可能催生类似心理治疗保密特权的立法讨论，也影响企业选型与合规评估。
- **关键细节：** Altman 称缺乏 AI 法律与政策框架是当前主要问题之一；该话题与本周欧盟 GPAI 准则适用倒计时（8 月 2 日）形成呼应，个人数据与模型义务的监管讨论同步升温。
- **来源：** https://techcrunch.com/2025-07-25/sam-altman-warns-theres-no-legal-confidentiality-when-using-chatgpt-as-a-therapist/

- **关键细节：** 异构混训直指不同芯片、不同地域集群的统一调度难题；信通院测试覆盖芯片、框架、模型全栈，为后续国产化采购提供标准依据。

## 三、本周行业变化总结

本周是"政策周"与"基建周"：美国一天内把行动计划、数据中心审批、技术栈出口、价值取向审查打包落地，AI 治理彻底内政化、工具化；OpenAI-Oracle 的 4.5 吉瓦协议则证明头部实验室的竞争力越来越取决于能锁定多少电力与机房。产品层面，编程 Agent 成为最密集的战场：Qwen3-Coder 开源登顶、Claude Code 网页化、Flash-Lite 平价化，三件事共同指向"代理式编程从演示走向规模化日常使用"。研究层面，HRM 与"长思考反而降准确率"的论文对纯 Scaling 路线发出杂音。中国侧则呈现"国产替代加速 + 外资研发收缩"的双向重构。

## 四、本周趋势分析

1. **AI 竞争能源化、土建化：** 4.5GW 级数据中心协议与联邦审批松绑同周出现，算力单位从"卡"变成"瓦"，电力与土地成为瓶颈资源，资本开支周期将外溢至公用事业与建设板块。
2. **编程 Agent 进入"云端并行"形态：** Claude Code 网页版与 Qwen3-Coder 的 agentic 定位显示，单线程补全已终结，多任务并行、托管沙箱、自动 PR 成为新基线；开源旗舰编程模型的出现将压低闭源定价权。
3. **推理的"性价比战争"开启：** Flash-Lite 主打每美元智能，Anthropic 论文质疑长推理收益，"智能/成本"取代"智能上限"成为采购决策主指标。
4. **主权 AI 叙事落地：** 英国与 OpenAI 双边协议、美国技术栈出口令、中国信通院全栈适配测试，三种路径同周出现，各国都在把 AI 栈的主权可控当作产业政策核心。

## 五、值得尝试的工具与工作流

- **Qwen3-Coder + 通义灵码：** 免费不限量，适合把开源编程 Agent 接入内部代码库做批量修复与测试生成；自部署可用 vLLM 类框架跑 256K 长上下文。
- **Claude Code 网页版：** 适合"下班后排任务"：并行修 Bug、生成 PR，早上一键 review；注意托管环境权限最小化。
- **Gemini 2.5 Flash-Lite：** 高并发摘要、分类、路由等廉价推理负载的首选试验对象，可与其上一代 Flash 做每美元智能对比。
- **工作流建议：** 用 Flash-Lite 做任务路由、旗舰模型做复杂编码、网页 Agent 做批量执行的三层组合，是当前性价比最高的编程 Agent 流水线。
