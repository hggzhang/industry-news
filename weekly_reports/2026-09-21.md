# AI 周报｜2026-09-21 至 2026-09-27

**统计周期：** 周一 00:00 至周日 23:59:59（Asia/Shanghai）

## 一、本周核心结论

1. 前沿实验室一周内三连发：Anthropic 的 Claude Opus 5.5（9 月 22 日）、OpenAI 的 GPT-6 Sol 与 GPT-6 Luna（9 月 22 日）、xAI 的 Grok 4.7（9 月 21 日）先后上线，9 月下旬成为年内密度最高的"发布窗口"。
2. 定价战从"旗舰降价"扩展到"梯队重构"：Opus 5.5 比 Opus 5 输入输出各降 20%、缓存读价降 60%；GPT-6 Luna 把输入价压到 0.10 美元/百万 token；Grok 4.7 宣称"速度翻倍、价格减半"。前沿能力的单位价格在一个月内被反复重写。
3. Claude Opus 5.5 登顶独立评测榜首并成为 Claude Code 默认模型，同时 Claude Code 把"自动模式"设为默认权限模式——编程智能体的"默认放手"成为头部厂商的产品共识，与上周框架 3.0 的"高危操作人工审批"要求形成微妙张力。
4. 开源战线全面开花：小米开放 MiMo-V2.6 系列，斯坦福与 NVIDIA 推出动作评分模型 CLM-8B（Apache 2.0），美团、MiniMax、Yandex、Upstage、NaiveAI 等同周上新，"每周都有新权重"已成常态。
5. 智能体安全与 AI 云继续吸金：AI 智能体治理安全公司 Island 完成 4 亿美元 F 轮（估值 64 亿美元），芬兰全栈 AI 云 Verda 融资 1.89 亿美元，资本正在为"智能体大规模上岗"配置保险与底座。

## 二、本周重要事件

### 1. [重大] [模型发布] Anthropic 发布 Claude Opus 5.5：独立评测新科第一，降价 20% 并接管 Claude Code 默认位

- **发生了什么：** 9 月 22 日，Anthropic 发布 Claude 5.5 家族旗舰 Opus 5.5：1M token 上下文、128K 最大输出，面向长时间运行的智能体编程与知识工作。定价每百万输入 4 美元、输出 20 美元，较 Opus 5（5/25 美元）下降 20%，缓存读从 0.50 降至 0.20 美元（降幅 60%），官方称典型工作负载整体成本较 Opus 5 低约 40%；同时提供 Fast 模式。CSuite 的 9 月模型盘点记录其以 58 分成为新的独立评测第一。发布当日，Claude Code 自 v2.1.280 起将 Opus 5.5 设为默认模型，v2.1.283 起进一步把"自动模式"设为默认权限模式。
- **为什么重要：** 缓存读降价 60% 精准打击智能体工作流的最大成本项，说明头部实验室的价格武器已经细化到"按工作负载结构定价"；Claude Code 默认切换加默认自动授权，等于把数亿行生产代码的日常编辑权默认交给新旗舰，这是模型厂商对"信任"的一次公开下注，也把智能体权限治理的紧迫性再次推上台面。
- **关键细节：** Batch API 输入输出五折；1 小时缓存写 8 美元/百万 token；Opus 5.5 系统卡片同期发布。
- **来源：** https://www.anthropic.com/claude-opus-5-5 ；https://platform.claude.com/docs/en/models/opus-5-5/overview ；https://csuite.so/blog/ai-models-roundup-september-2026 ；https://developertoolkit.ai/en/resources/whats-new/

### 2. [重大] [模型发布] OpenAI 发布 GPT-6 Sol 与 GPT-6 Luna：中档降价一半、低档进入"美分时代"

- **发生了什么：** 9 月 22 日，OpenAI 推出 GPT-6 Sol 与 GPT-6 Luna 两款模型，官方定位为"以不同能力与成本组合，将前沿智能带入日常工作"。价格同步下调：Sol 输入从 4 美元降至 2 美元/百万 token、输出从 20 美元降至 10 美元；Luna 输入从 0.20 美元降至 0.10 美元、输出从 1.20 美元降至 0.50 美元，OpenRouter 上 Luna 的缓存读低至 0.01 美元/百万 token。两款模型均支持 Fast 模式（按标准价 2 倍计）。
- **为什么重要：** 与 Anthropic 同日发布，OpenAI 用"梯队降价"回应：旗舰 Astra 维持高价与受控访问，Sol 承接主力生产力场景，Luna 把"接近前沿"的能力卖到美分级，GPT-6 家族完成对价格带的全面覆盖。0.10 美元输入价意味着"智能体随便跑"的经济性拐点提前到来，中小开发者与高频工具调用场景是直接受益者。
- **关键细节：** OpenAI 研究发布页将两者列为"产品"条目；企业侧 ChatGPT 费率卡同步收录 Sol/Luna 的 Fast 模式倍率。
- **来源：** https://openai.com/zh-Hans-CN/research/index/release/ ；https://openrouter.ai/openai/gpt-6-luna ；https://luminous-core.net/2026/09/gpt-6-sol-luna-debut/ ；https://help.openai.com/en/articles/20001415-chatgpt-rate-card-enterprise-token-based-pricing

## 三、本周行业变化总结

本周的主旋律是"梯队定价 + 默认权争夺"。Anthropic 与 OpenAI 在同一天（9 月 22 日）分别用 Opus 5.5 和 Sol/Luna 重写价格表，降价重点从表面单价转向缓存、批量与工作负载结构，说明双方都清楚智能体时代的真实成本在"重复读取与长时间运行"。xAI 的 Grok 4.7 则展示了渠道分发速度：发布当天即进入 GitHub Copilot 与 Cursor。工具侧，Claude Code 把新旗舰与自动模式同时设为默认，"默认放手"与上周中国框架 3.0"高危操作人工审批"形成东西方治理节奏的对照，智能体安全公司 Island 的 64 亿美元估值正是这一张力的市场化定价。开源侧，小米、美团、MiniMax、斯坦福×NVIDIA 与全球长尾同周上新，权重供给的丰富度第一次超过多数团队的评测跟进能力。

## 四、本周趋势分析

1. **价格战进入"结构定价"阶段。** 缓存读降 60%、Luna 输入 0.10 美元、Grok"半价"：单一 token 价不再是战场，缓存策略、批量折扣与模式倍率成为采购比价的核心项。
2. **默认模型即护城河。** Opus 5.5 当日成为 Claude Code 默认、GPT-6 Astra 此前成为 Codex 默认、Grok 4.7 当日进 Copilot/Cursor——实验室竞争已从"谁更强"转向"谁在用户的默认下拉框里"。
3. **智能体治理产业化的信号明确。** 权限默认放开（Claude Code auto mode）与监管事前设限（框架 3.0）同时发生，中间地带被资本填补：动作评分开源化（CLM-8B）、智能体安全独角兽（Island）都在本周出现。
4. **开源"周更化"带来选型债务。** 一周十余个新权重，评测分数（AA 榜、Terminal-Bench、DeepSWE 等）口径不一，企业侧"评测-灰度-回滚"流水线能力比模型发现能力更稀缺。

## 五、值得尝试的工具与工作流

1. **Claude Code 自动模式试点：** 若团队已在用 Claude Code，可在隔离分支上体验 v2.1.283 的默认自动模式，同时用 claude plugin eval 与权限清单评估高危操作边界——正好对照框架 3.0 的"人工审批"要求做一次内部演练。
2. **GPT-6 Luna 跑高频批处理：** 0.10 美元输入、0.01 美元缓存读，适合做大规模分类、路由、抽取等"系统一"任务，把复杂推理留给 Sol/Astra，形成分层调用。
3. **Grok 4.7 作为 Copilot 第二引擎：** 发布即上线 GitHub Copilot 与 Cursor，按列表价计费，适合在长仓库重构任务中与 Opus 5.5 做 A/B 对比。
4. **CLM-8B 嵌入智能体运行时：** Apache 2.0 的动作评分器可挂在现有 8B 底座前做动作预筛，低延迟场景（GUI 操作、工具选择）值得 POC。
5. **LongCat-2.5-Preview 兼容 Claude Code：** 想用 Claude Code 工作流但需要国产/自有权重团队的，可直接以 Preview 模型接入验证。
