# AI 周报｜2025-02-24 至 2025-03-02

**统计周期：** 周一 00:00 至周日 23:59:59（Asia/Shanghai）

## 一、本周核心结论

1. Anthropic 于 2 月 24 日发布 Claude 3.7 Sonnet，这是业界首个"混合推理"模型（即时回答与扩展思考两种模式合一），并同步推出命令行编程智能体 Claude Code，直接对标并升级了 AI 编程赛道。
2. DeepSeek 在 2 月 24 日至 28 日举办"开源周"，连续开源 FlashMLA、DeepEP、DeepGEMM、3FS 以及 DualPipe、EPLB 等基础设施代码库，把竞争焦点从"模型权重开源"推进到"推理/训练系统层开源"。
3. OpenAI 于 2 月 27 日推出 GPT-4.5 研究预览版（面向 ChatGPT Pro/Plus/Team）并将 o3-mini 升级为 o3-mini-high，采取"大模型+推理模型"双轨更新策略。
4. Google 在同一周内密集出牌：Gemini 2.0 Pro Experimental 面向开发者开放，视频模型 Veo 3 首次支持原生音频生成并配套推出 AI 制片工具 Flow。
5. 中国厂商跟进开源：阿里 2 月 25 日开源 QwQ-Max-Preview 深度思考模型与通义万相 2.1 视频生成模型（Apache 2.0），DeepSeek 则宣布 API 错峰降价（V3 五折、R1 二五折），价格战从模型层蔓延到推理服务层。
6. 本周被多家机构称为"开源盛世"式的密集更新周：中美头部实验室在同一周内全部发布重磅更新，行业进入"月度甚至周度"的新品节奏。

## 二、本周重要事件

### 1. [重大] [大模型发布] Anthropic 发布 Claude 3.7 Sonnet 与编程智能体 Claude Code
- **发生了什么：** 2 月 24 日，Anthropic 发布 Claude 3.7 Sonnet，官方称其为"首个混合推理模型"，既能在数秒内给出即时回答，也能打开"扩展思考"模式逐步推理；模型在编码与前端开发上达到行业先进水平。同日推出命令行工具 Claude Code（研究预览），允许开发者在终端中把复杂工程任务直接委托给 Claude。Claude 3.7 Sonnet 向 Free、Pro、Team、Enterprise 全量套餐及开发者平台开放。
- **为什么重要：** 混合推理把"快答"与"深思"合并进单一模型，是产品形态上的分水岭；Claude Code 把智能体编程从 IDE 插件推进到终端工作流，直接冲击软件开发范式，也为后续各家编程智能体竞赛定下基调。
- **关键细节：** 官方强调其在编码、内容生成、数据分析与规划上的显著提升；开发者平台同日记录 Claude 3.5 Haiku 增加视觉（图像理解）能力。
- **来源：** https://www.anthropic.com/news/claude-3-7-sonnet ；https://docs.claude.com/en/release-notes/overview ；https://www.anthropic.com/news/visible-extended-thinking

### 2. [重大] [开源生态] DeepSeek 启动"开源周"，连续开源五大基础设施代码库
- **发生了什么：** 2 月 24 日至 28 日，DeepSeek 按每日一项的节奏开源：首日 FlashMLA（面向 Hopper GPU 的高效 MLA 解码内核，H800 实测内存带宽达 3000 GB/s）；次日 DeepEP（首个面向 MoE 训练与推理的专家并行通信库，支持 FP8 与 NVLink/RDMA）；2 月 26 日 DeepGEMM（高效 FP8 GEMM 库，核心代码仅约 300 行）；随后开源 3FS（高性能分布式文件系统）以及 DualPipe、EPLB 等训练代码。
- **为什么重要：** 新华网评论称此举"打响了 AI 新一轮开源竞赛的发令枪"，AI 进入"开源盛世"。DeepSeek 开源的不是模型而是支撑大规模推理/训练的系统软件，意味着其把 R1 低成本优势的技术根基建到了行业公共底座上，直接利好所有在 NVIDIA GPU 上跑大模型的团队。
- **关键细节：** FlashMLA 专为可变长度序列优化且已投入生产使用；DeepGEMM 支持密集与 MoE 架构；开源周共涉及 5 个以上代码库，GitHub 提交记录被开发者称为"赛博烟花"。
- **来源：** https://news.cctv.com/2025-02-24/ARTIYzdw9KThK8h2oydrEWf5250224.shtml ；http://www.news.cn/tech/20250227/4bcf1510c5ac42b3ac26f3eb5c3e89bb/c.html ；https://cloud.tencent.cn/developer/article/2522822 ；https://cloud.tencent.cn/developer/article/2505202

### 3. [重大] [大模型发布] OpenAI 推出 GPT-4.5 研究预览版，o3-mini 升级 o3-mini-high
- **发生了什么：** 2 月 27 日，OpenAI 在模型发布说明中宣布推出 GPT-4.5 研究预览版，称其为"迄今规模最大、也最适合聊天的模型"，通过扩大预训练与后训练规模、扩展无监督学习，显著提升了不依赖显式推理时的模式识别与联系建立能力；同日 o3-mini 增加 high 推理强度档位（o3-mini-high）。
- **为什么重要：** GPT-4.5 是 GPT 系列基础模型在推理模型时代的一次"压轴"升级，主打自然语言与"情商"；o3-mini-high 则补齐了 OpenAI 低价推理档位的深度。两条线同时更新，显示 OpenAI 在 Claude 3.7 发布后不到一周即快速反击。
- **关键细节：** OpenAI 官方帮助中心将本次发布标注为"推出 GPT-4.5（2025 年 2 月 27 日）"，面向 ChatGPT 付费用户开放研究预览。
- **来源：** https://help.openai.com/zh-hans-cn/articles/9624314-模型发布说明

### 4. [重要] [AIGC 视频] Google 发布 Veo 3 与 AI 制片工具 Flow，视频生成首次"原生带声"
- **发生了什么：** 2 月下旬，Google 公布新一代视频生成模型 Veo 3：在 Veo 2 画质基础上首次支持原生音频生成——街道环境噪音、公园鸟鸣乃至角色对白都可随画面一并生成，并支持从文本和图像生成视频；同时推出面向创作者的 AI 制片工具 Flow，围绕 Veo、Imagen 与 Gemini 组合工作流设计，帮助创作者生成电影感片段与场景。
- **为什么重要：** 原生音频把"文生视频"从无声片段推进到可直接使用的视听内容，是 AIGC 视频赛道的关键拐点；Flow 则标志着 Google 从"发模型"转向"发创作工具"，与 OpenAI Sora、快手可灵等正面竞争。
- **关键细节：** DeepMind 官方页面称 Veo 3 在物理表现、真实感与提示词遵循上达到一流水平，并支持更长视频与扩展创意控制。
- **来源：** https://blog.google/innovation-and-ai/products/google-flow-veo-ai-filmmaking-tool/ ；https://deepmind.google/en/models/veo/

### 5. [重要] [大模型发布] Gemini 2.0 Pro Experimental 上线：200 万 token 上下文的编码旗舰实验版
- **发生了什么：** 2 月 26 日前后，Google 发布 Gemini 2.0 Pro Experimental，官方称这是其"迄今编码性能最强、处理复杂提示能力最好的模型"，对世界知识的理解与推理均优于此前发布的任何 Gemini 模型，并提供 Google 模型中最大的 200 万 token 上下文窗口。
- **为什么重要：** 2.0 Pro 补上了 Gemini 2.0 家族此前缺位的"大杯"旗舰，200 万 token 上下文对代码库级分析与长文档智能体工作流是硬需求，直接对标 OpenAI 与 Anthropic 的开发者场景。
- **关键细节：** 该版本以 Experimental 形式先行向开发者开放；此前 Google 已于 2 月中旬将 Gemini 2.0 Flash-Lite 转为正式 GA 版本，主打速度、可扩展性与成本效益。
- **来源：** https://blog.google/technology/google-deepmind/gemini-model-updates-february-2025/ ；https://ai.google.dev/gemini-api/docs/changelog

### 6. [重要] [开源模型] 阿里开源 QwQ-Max-Preview 深度思考模型与通义万相 2.1 视频模型
- **发生了什么：** 2 月 25 日，阿里开源 QwQ-Max-Preview 深度思考模型，支持联网搜索与思维链可视化，并计划以 Apache 2.0 协议完全开源；同日阿里云宣布开源通义万相 2.1 视频生成模型，提供 1.3B 与 14B 两种参数版本，以 Apache 2.0 开放全部推理代码与权重，该模型在 VBench 评测中以 86.22% 的成绩位居视频生成榜单前列。
- **为什么重要：** 在 DeepSeek 开源周带动下，中国头部厂商把"深度思考模型+视频生成模型"同时开源到 Apache 2.0 级别，开源阵营的可用武器库一周内大幅扩容，也压低了闭源厂商的 API 定价空间。
- **关键细节：** 通义万相 2.1 的 14B 版本为当时开源视频模型中参数规模较大的一档；QwQ 系列是通义团队以推理能力著称的"实验性"产品线。
- **来源：** https://m.36kr.com/p/3201742636306567

### 7. [一般] [价格与商业化] DeepSeek 开放平台 API 推出"错峰优惠"：夜间 R1 低至 2.5 折
- **发生了什么：** 2 月 26 日，DeepSeek 官方微信宣布即日起在每日北京时间 00:30 至 08:30 的夜间空闲时段推出错峰优惠：DeepSeek-V3 API 调用价格降至原价 50%，DeepSeek-R1 降至原价 25%，鼓励用户利用低峰时段获得更经济流畅的调用体验。
- **为什么重要：** 这是大模型行业少见的"分时定价"实践，把电力/云计算行业的峰谷逻辑引入推理服务，既缓解白天算力拥堵，也进一步拉低 R1 的使用门槛，加速开发者向国产 API 迁移。
- **关键细节：** 优惠仅面向开放平台 API 调用时段定价，网页与 App 对话入口不在此次调整公告范围内表述。
- **来源：** https://stcn.com/article/detail/1548974.html

### 8. [一般] [多模态更新] Claude 3.5 Haiku 增加视觉能力，小模型多模态化提速
- **发生了什么：** 2 月 24 日，Claude 开发者平台发布说明记录：Claude Haiku 3.5 增加视觉支持，可分析与理解图像，与同日发布的 Claude Sonnet 3.7（可产出即时响应或展示逐步扩展思考）一并上线。
- **为什么重要：** 最便宜、最快的 Haiku 档获得图像理解能力，意味着"多模态+低延迟+低成本"组合正式进入主流 API 产品线，为大规模智能体（屏幕理解、截图操作）场景提供了更经济的底座。
- **关键细节：** 官方将 Sonnet 3.7 描述为"One model, two ways to think"（一个模型，两种思考方式）。
- **来源：** https://docs.claude.com/en/release-notes/overview

## 三、本周行业变化总结

本周是典型的"超级发布周"：Anthropic、OpenAI、Google、DeepSeek、阿里五家在同一 7 天窗口内全部推出重磅更新，节奏从"季度级"压缩到"周级"。竞争结构出现两个清晰变化：其一，推理能力产品化——混合思考/扩展思考成为新标配，模型开始同时卖"快"和"深"；其二，开源从模型权重下沉到系统软件，DeepSeek 用 FlashMLA/DeepEP/3FS 把低成本推理的可复制性直接公开，配合通义万相 2.1、QwQ-Max-Preview，开源生态的"可用度"单周内跃升。价格层面，DeepSeek 错峰降价把成本竞争推向服务运营维度。AIGC 视频在 Veo 3 原生音频与通义万相开源的双向冲击下，正式进入"有声视频+开源可部署"的新阶段。

## 四、本周趋势分析

1. **混合推理成为新范式：** Claude 3.7 Sonnet 的"单模型双模式"很可能被快速跟进，"即时/深思"开关将取代"推理模型/普通模型"的二元划分，成为 API 与订阅产品的标准设计。
2. **编程智能体竞赛全面开打：** Claude Code 把智能体编程带到终端，Gemini 2.0 Pro 主打编码与超长上下文，OpenAI 也必然在开发者工具线加码；"从补全到委托"的叙事成为各家共识。
3. **开源竞争系统化：** 比拼焦点从"谁的权重更大"转向"谁的基础设施更好用"，DeepSeek 系统级开源让 Hopper GPU 利用率成为公共知识，中小团队部署成本显著下降。
4. **中国厂商"开源+降价"组合拳：** 阿里全面 Apache 2.0 开源叠加 DeepSeek 分时降价，对闭源 API 形成价格与生态双重挤压，海外厂商定价策略或将被迫跟进。
5. **视频生成进入"有声时代"：** Veo 3 原生音频抬高了行业门槛，纯画面生成工具（包括部分早期开源模型）面临代差压力。

## 五、值得尝试的工具与工作流

- **Claude Code：** 已在终端工作的工程师可立即申请研究预览，把跨文件重构、修 bug、写测试等任务委托给模型，体验"终端原生智能体编程"。
- **FlashMLA / DeepGEMM：** 在 H800/H100 上自部署 DeepSeek-V3/R1 或 MLA 架构模型的团队，可直接替换解码内核与 GEMM 库以压榨吞吐，官方仓库即插即用。
- **o3-mini-high：** ChatGPT 付费用户可在难题上切换 high 推理档，对比 o1 在数学/代码任务上的性价比。
- **Gemini 2.0 Pro Experimental：** 需要整仓代码理解或超长文档分析（百万级 token）的开发者，可用 2M 上下文窗口测试"一次喂入"工作流。
- **通义万相 2.1（14B）：** 需要私有化视频生成的团队可基于 Apache 2.0 权重与推理代码直接部署，成本远低于调用闭源 API。
