## 二、本周重要事件

### 1. [重大] [资本市场] Anthropic 秘密递交 IPO 申请，万亿级上市排队开始
- **发生了什么：** 6 月 1 日，Anthropic 在关闭 650 亿美元 H 轮（投后估值 9650 亿美元）不到一周后，向美国 SEC 秘密提交了 IPO 招股书（S-1）草案。秘密通道允许公司在公开前与监管机构打磨披露内容，上市时点取决于 SEC 审查与市场条件，公司尚未确定发行股数与价格。Anthropic 由此在上市竞赛中领先 OpenAI，两家均瞄准今秋；加上已公开 S-1 的 SpaceX，三笔潜在万亿美元级 AI 上市挤进同一窗口。
- **为什么重要：** 这是 IT 采购方首次将获得前沿实验室的审计财报、收入集中度、算力成本与法律风险披露——过去评估一家前沿 AI 公司只能依赖运行率口径的自述数字。同时，法律与监管影响将随招股书公开而摆上台面：Florida 诉 OpenAI 案提醒市场，这些公司携带的风险因素将首次被逐条写进公开文件。
- **关键细节：** 上周 OpenAI 被曝也在准备秘密 IPO 文件（目标 9 月、估值超 1 万亿美元）；Info-Tech 建议企业在秋季披露落地前暂缓签署多年期承诺。
- **来源：** https://techcrunch.com/2026-06-01/anthropic-files-to-go-public/ ；https://www.infotech.com/software-reviews/vendor-technology-notes/big-5-ai-vendor-roundup-week-of-june-1-2026

### 2. [重大] [大模型发布] Microsoft Build 2026 发布七款自研 MAI 模型：后 OpenAI 时代的完整模型栈
- **发生了什么：** 6 月 2 日 Build 2026 大会上，Mustafa Suleyman 领导的 Microsoft AI superintelligence 团队一次性发布七款完全自研模型：MAI-Thinking-1（公司首个推理模型，稀疏 MoE 架构、约 1 万亿总参数 / 350 亿活跃参数、25.6 万 token 上下文）、MAI-Code-1 与 MAI-Code-1-Flash、MAI-Image-2.5（含 Flash 变体）、MAI-Transcribe-1.5、MAI-Voice-2。官方强调全部使用干净商业授权数据从零训练，未从 OpenAI 或任何第三方模型蒸馏。Microsoft 称 MAI-Thinking-1 在 SWE Bench Pro 上达到 Claude Opus 4.6 的编码水平、盲评优于 Claude Sonnet 4.6（均为自报数据）。MAI-Code-1-Flash 本月起进入所有 GitHub Copilot 套餐，MAI-Image-2.5 已上线 PowerPoint 与 Foundry，其余模型经 Foundry、Fireworks AI、Baseten、OpenRouter 提供。
- **为什么重要：** 数周来被逐条追踪的“模型独立”策略正式变成产品线：结合上月对 Inception 的收购谈判与内部 Claude Code 下线，Microsoft 在开发者栈的每一层都提供了自研备选，并把 Foundry 与 Copilot 定为所有模型之上的统一编排层。但并非与 OpenAI 决裂——Azure 仍是 OpenAI 主力基础设施，M365 Copilot 仍含 OpenAI 能力；变化在于 Microsoft 不再依赖任何单一模型伙伴。
- **关键细节：** 同期发布 Copilot 治理控制工具、Copilot+ PC 端侧 MAI 支持预览，机密计算微调 API 将于三季度公开预览。
- **来源：** https://finance.biggo.com/news/202606021923_Microsoft-MAI-Thinking-1-reasoning-model-Build-2026 ；https://www.infotech.com/software-reviews/vendor-technology-notes/big-5-ai-vendor-roundup-week-of-june-1-2026 ；https://www.news.cn/20260701/d9a7a20080c24c4b8febfed1ae010dd3/c.html

### 3. [重大] [企业落地] OpenAI 前沿模型与 Codex 正式登陆 AWS Bedrock
- **发生了什么：** 6 月 1 日，OpenAI 的 GPT-5.5、GPT-5.4 与 Codex 从春季的有限预览转为在 Amazon Bedrock 正式 GA：数百万 AWS 客户可经由 Bedrock 的安全、治理与按 token 计费体系调用 OpenAI 模型，企业可以沿用既有的采购与合规流程引入 OpenAI。AWS 给出的选型指引是最重负载用 GPT-5.5、追求性价比用 GPT-5.4。
- **为什么重要：** 这是 OpenAI 迄今最重要的渠道扩张之一，也标志着云厂商与模型厂商关系重构：Bedrock 同时承载 OpenAI 与 Anthropic 的前沿模型，AWS 把自己定位成“任何实验室的模型都能在同一套管控下运行”的中和多模型平台；而 OpenAI 也明确选择“在所有云上可用”而非绑定单一云。对企业而言，“选哪个供应商”的问题正在让位于“如何跨供应商保持可迁移性”。
- **关键细节：** 同期 Bedrock 路线图上还有 AgentCore 支付、Agent Toolkit 与 Claude Platform on AWS；Microsoft 侧 Azure 仍是 OpenAI 的主要基础设施。
- **来源：** https://openai.com/index/openai-frontier-models-and-codex-are-now-available-on-aws/ ；https://aws.amazon.com/blogs/aws/get-started-with-openai-gpt-5-5-gpt-5-4-models-and-codex-on-amazon-bedrock/

### 4. [重要] [政策监管] Anthropic 发文《When AI Builds Itself》：呼吁建立可验证的行业协同暂停机制
- **发生了什么：** 6 月 4 日，Anthropic 旗下 Anthropic Institute 发布长文（作者 Marina Favaro 与 Jack Clark），主张前沿实验室应构建一个跨国、可验证的机制，在 AI 系统自我改进的速度超过社会可管理范围时协同放缓或暂时暂停开发。文中给出内部数据：截至 2026 年 5 月，Anthropic 代码库中超 80% 的合入代码由 Claude 编写（Claude Code 上线前的 2025 年初仅为个位数比例）；工程师人均日合入代码量约为 2024 年的 8 倍；模型可自主完成任务的时长每约 4 个月翻一番。Anthropic 称这条路通向“递归自我改进”，但表示只有在多国多家前沿实验室在可核查条件下共同同意时才会支持暂停——单边暂停只会改变领跑者。
- **为什么重要：** 这是前沿实验室对“能力在加速而非趋稳”的最坦率公开承认，直接把递归自我改进从思想实验变成有运营数据的议程；其治理含义（评估周期要缩短、AI 治理要自适应）将影响所有企业买家。批评者注意到时机的微妙：在秘密递交 IPO 数天后呼吁行业减速，客观上也会把竞争格局冻结在现任领先者一侧——安全论点与在位者优势可以同时为真。
- **关键细节：** Anthropic Institute 计划未来数月召集政策制定者、研究者与其他实验室讨论机制设计；安全社区（如 CSA）已跟进发布企业安全影响白皮书。
- **来源：** https://www.anthropic.com/institute/recursive-self-improvement ；https://aiempowered.ai/news/anthropic-global-ai-pause ；https://labs.cloudsecurityalliance.org/wp-content/uploads/2026/06/CSA_whitepaper_ai_recursive_self_improvement_systemic_risk_v1.0-csa-styled.pdf

### 5. [重要] [安全] Project Glasswing 扩容至约 150 家新机构，欧盟网络安全局 ENISA 首次加入
- **发生了什么：** 6 月 2 日 Anthropic 宣布将 Claude Mythos Preview 的访问范围扩大约 150 家组织、覆盖 15 个以上国家，重点纳入首批计划中代表性不足的电、水、医疗、通信与硬件行业，其中大量是代码嵌入关键基础设施的软件供应商；首批约 50 家合作伙伴已用 Mythos 发现逾 1 万个高危及以上漏洞。新伙伴须先满足安全要求方可接入。Anthropic 同时吸纳了首个欧盟机构成员 ENISA，并称该扩容与美国政府协作设计。
- **为什么重要：** Mythos 正从科技与金融公司的小圈子进入运营技术与基础设施层：如果你的组织运行电力、水务、医疗或通信系统（或依赖此类供应商），大规模零日发现能力正在抵达你的行业，此前反复讨论的“补丁窗口压缩”将加速到来。部分安全研究者认为，更大范围的铺开是 Mythos 级能力最终公开发布的前奏。
- **关键细节：** Anthropic 估计多数入选组织若遭重大泄露可能影响超过 1 亿人。

### 6. [重要] [AIGC视频] Google 发布 Gemini Omni：首个“任意输入、对话式编辑”的视频生成模型家族
- **发生了什么：** 6 月 1 日 Google 正式推出 Gemini Omni 模型家族，这是 I/O 预告能力的落地：模型可接受图像、音频、视频与文本输入，生成锚定真实世界知识的高质量视频，并支持用自然语言对话持续修改已生成视频。家族首个模型 Omni Flash 即日起开始推送，后续将面向开发者与企业客户经 Gemini API 与 Agent Platform 开放。
- **为什么重要：** 此前多模态模型的边界是“理解”，Omni 把“生成 + 可对话编辑”做进了同一模型家族，直接冲击 Runway、Kling 等以剪辑控制为卖点的专业视频工具；对话式迭代也意味着视频生产的工作流范式从“参数调优”转向“意图表达”。结合 Nano Banana 2 的视频输入能力，Google 正在把图像与视频创作全面并入 Gemini 分发体系。
- **关键细节：** 发布节奏延续 I/O 后“预览快速转 GA”的路线；Gemini 3.5 Flash 也在本周推进 GA 进程（6 月 8 日起成为 Gemini Enterprise 默认模型）。

### 7. [重要] [政策监管] 佛罗里达州对 OpenAI 与 Sam Altman 提起全美首例州级诉讼
- **发生了什么：** 6 月 1 日，佛罗里达州总检察长 James Uthmeier 对 OpenAI 及 CEO Sam Altman 提起 83 页民事诉讼，指控公司明知产品可能伤害用户仍进行欺骗性推广、为追求市值牺牲安全，并寻求让 Altman 承担个人责任；诉状包含四项欺骗与不公平交易行为指控，此前该州已就 ChatGPT 涉嫌卷入的悲剧事件展开调查。OpenAI 此前已否认相关责任。
- **为什么重要：** 这是美国首例由州总检察长直接针对前沿 AI 实验室及其 CEO 的执法诉讼，意味着在 Musk 案败诉后，OpenAI 的法律与监管阴云并未散去，反而从私人诉讼升级到公权力问责；对即将 IPO 的公司而言，这类风险因素将必须写入公开招股书，成为所有企业买家的评估项。
- **关键细节：** 诉讼把“AI 竞赛优先于安全警告”作为核心叙事，预计将引发其他州跟进；企业侧的安全事件（见事件 5 的 Mythos 扩容）与监管动作在同一周叠加，攻防与问责同步升温。

### 8. [重要] [AI编程工具] GitHub Copilot 切换按量计费（AI Credits），开发者几乎一致差评
- **发生了什么：** 6 月 1 日起，GitHub Copilot 从固定费率加请求限额的旧模式切换为基于 token 用量的“AI Credits”计费。早期开发者反应几乎一边倒地负面：重度使用 Agent 功能的用户面临难以预估的账单。
- **为什么重要：** 与上周 Microsoft 内部下线 Claude Code 的决策互为镜像：Agent 编程工具的 token 计价让“人均成本”变得高度不可预测，这正是大厂推动工具收敛、企业重谈合同的直接原因。编程 Agent 从“席位费”时代进入“用量经济”时代，成本治理将成为 CTO 办公室的常规议题。
- **关键细节：** 同期 MAI-Code-1-Flash 进入所有 Copilot 套餐，Microsoft 用自研模型压低边际成本的动作与计费改革同步发生；OpenAI 亦于 6 月 4 日在 ChatGPT 推出可选的 Lockdown Mode 高安全沙箱（限制实时浏览、深度研究、文件下载与 Agent 模式以对抗提示注入），以及约 5 倍算力效率的 Dreaming V3 自动记忆架构（先向美国 Plus/Pro 用户推送）。

## 三、本周行业变化总结

## 四、本周趋势分析

- **递归自我改进从概念变成有数据的议程。** 80% 合入代码由 Claude 编写、任务时长每 4 个月翻倍——Anthropic 用内部运营数据证明“AI 研发 AI”已是进行时，暂停机制的讨论将外溢到政策圈。

- **Agent 经济学的成本面开始显形。** Copilot 按量计费的差评、Microsoft 内部工具收敛、自研模型降边际成本——token 用量的不可预测性正在成为 Agent 规模化的第一道财务闸门。
