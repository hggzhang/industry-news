## 二、本周重要事件

### 1. [重大] [政策监管] 阿姆斯特丹法院禁令：Grok 被禁止生成非自愿性意象，违者每日罚 10 万欧元
- **发生了什么：** 3 月 26 日，荷兰阿姆斯特丹地区法院（案号 ECLI:NL:RBAMS:2026:3106）就网络滥用专业机构 Offlimits 联合荷兰受害者支持基金起诉 xAI 与 X 平台的简易程序作出中间判决，禁止 X 与 xAI 在荷兰境内生成和传播针对荷兰居民的"脱衣"类非自愿性意象及儿童性虐待内容，并禁止在违规期间继续向荷兰用户提供 Grok 的相关功能；不执行判决将面临每日 10 万欧元罚款，上限 1000 万欧元。反数字仇恨中心（CCDH）的统计显示，Grok 曾在 11 天内生成约 300 万张性化图像，其中约 2.3 万张涉及未成年人。判决公布于 3 月 27 日引发全球报道。
- **为什么重要：** 这是欧洲第一份直接针对 xAI 的此类判决，标志着 AI 生成滥用图像从平台自律转向司法强制。值得注意的是，法院特别指出 Grok 的"脱衣"功能不区分被描绘者的地理位置，使滥用具有全球性外溢效应。同日欧洲议会投票通过禁止 AI 生成色情深度伪造，司法与立法在同一天的呼应显示欧盟对生成式 AI 内容滥用的容忍度已到临界点，对其他市场的平台合规将产生示范压力。
- **关键细节：** 本案由 Offlimits 获得荷兰受害者支持基金支持发起；判决要求 X 书面确认合规方式；CNBC、The Record 等均在 3 月 27 日报道此事。
- **来源：** https://uitspraken.rechtspraak.nl/details?id=ECLI%3ANL%3ARBAMS%3A2026%3A3106 ；https://merlin.obs.coe.int/article/10536 ；https://www.jls42.org/en/news/ia-actualites-27-mar-2026

### 2. [重大] [AIGC 视频] OpenAI 关停 Sora，AI 视频格局生变：可灵领跑、xAI 加码
- **发生了什么：** 彭博社 3 月 25 日报道以"OpenAI nixes Sora"为背景描述 xAI 的视频扩张：OpenAI 于本周关停了 Sora 独立应用与 API。第三方对比资料称，关停的直接原因是 Sora 月运营成本高达 800 万至 1200 万美元而订阅收入远不能覆盖；OpenAI 官方 Sora 页面亦确认该产品随后不再可用。与之形成对照的是，快手可灵 Kling 3.0（1080p Pro 版本）在 Artificial Analysis 文生视频（无音频）排行榜上位列第一，支持最长 15 秒生成与原生 4K/60fps；xAI 的 Grok Imagine 于 3 月 25 日宣布支持 15 秒 720p 带同步音频、背景音乐与音效的"视频故事"，马斯克称要在视频上"加倍投入"。
- **为什么重要：** Sora 退场意味着"通用消费级 AI 视频 App"路线在商业上遭遇重大挫折，高推理成本与订阅收入的倒挂是所有视频生成玩家共同面对的难题。空缺出来的市场正被两条路线瓜分：以可灵为代表的"把模型做成营收"的国产商业化路线，和以 Grok Imagine 为代表的"嵌入社交平台的低成本分发"路线。竞争重心从演示效果转向单位经济模型。
- **关键细节：** xAI 同日宣布 SuperGrok Lite 订阅（10 美元/月，含 480p、最长 6 秒视频生成），介于免费层与 30 美元/月的 SuperGrok Standard 之间。
- **来源：** https://www.bloomberg.com/news/articles/2026-03-25/musk-s-xai-doubling-down-on-ai-videos-after-openai-nixes-sora ；https://thebestaitools.co/comparisons/runway-vs-sora-vs-kling-ai-for-ai-video-generation/ ；https://www.tvtalk.cn/archives/11305

### 3. [重大] [大模型] Google 发布 Gemini 3.1 Flash Live：90+ 语言实时语音对话
- **发生了什么：** 3 月 26 日，Google 发布面向实时多模态对话的 Gemini 3.1 Flash Live，支持音频、图像、视频与文本输入，上下文窗口 12.8 万 token，覆盖 90 多种语言。相比上一代，模型可维持两倍时长的对话，对背景噪声与环境声的处理更好，复杂系统指令遵循更准，对话中触发外部工具更可靠，所有生成音频均嵌入 SynthID 水印。开发者可通过 Google AI Studio 的 Live API 接入，普通用户在 200 多个国家和地区通过 Gemini Live 与 Search Live 使用（Search Live 同步扩展并支持 Google Lens 视频），企业可通过 Vertex AI 部署。同月 Gemini Drops 更新还上线了 Lyria 3 Pro 音乐生成（单次生成最长 3 分钟完整结构歌曲）、免费的 Personal Intelligence（连接 Gmail、相册、YouTube 辅助规划）以及从 ChatGPT/Claude 导入记忆与聊天记录（支持 5GB zip）的迁移工具。
- **为什么重要：** 实时语音正从"演示功能"变成大厂的主战场入口。Gemini 3.1 Flash Live 把长对话、工具调用与多语言打包进 API 与搜索入口，配合"导入 ChatGPT/Claude 记忆"功能，Google 明显在抢夺存量助手用户的迁移成本高地。Lyria 3 Pro 与 SynthID 水印则显示 Google 在生成内容合规溯源上的持续投入。
- **关键细节：** 3 月 25-26 日 Gemini CLI v0.35.2 同步发布，子代理（subagents）默认启用、统一 SandboxManager 工具隔离；但 3 月 25 日起免费用户仅可使用 Gemini Flash，Pro 模型向付费订阅收紧，社区反应负面。
- **来源：** https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-1-flash-live/ ；https://blog.google/innovation-and-ai/products/gemini-app/gemini-drop-updates-march-2026/ ；https://www.jls42.org/en/news/ia-actualites-27-mar-2026

### 4. [重要] [开源模型] 美团开源 LongCat-Next：68.5B MoE 多模态长文本模型
- **发生了什么：** 3 月 27 日，美团技术团队开源新一代多模态大模型 LongCat-Next，同步上传至 GitHub 与 Hugging Face，供开发者免费商用。模型采用 68.5B 参数 MoE 混合专家架构，主打超长文本处理，支持最高 20 万字节的超长文本输入，兼顾语音、文本、图片多模态理解，对话延迟控制在毫秒级，并针对本地生活订单处理、客服咨询、业务流程审批等场景做了专项优化，支持企业二次微调与私有化部署。据艾媒网报道，开源首日社区下载量突破万次。
- **为什么重要：** LongCat-Next 延续了美团"垂直场景 + 开源开放"的路线：不做通用旗舰竞赛，而是把本地生活与客服业务里验证过的长文本、多模态能力开源，换取开发者生态与 B 端集成机会。20 万字节级长文本输入叠加 MoE 的低推理成本，对需要私有化部署的中小企业客服与流程自动化场景有直接吸引力。
- **关键细节：** 3 月 27 日同期，开源智能体框架 OpenClaw 发布 2026.3.22-beta.1 里程碑版本，为上线以来最大幅度重构：全面重写插件系统（第三方工具一键接入）、强化智能体安全隔离与多 Agent 任务编排，GitHub 星标突破 33 万。

### 5. [重要] [AI 编程工具] OpenAI Codex 上线原生插件：Slack、Figma、Notion、Gmail 开箱即用
- **发生了什么：** 3 月 26-27 日，OpenAI 将插件作为一等公民功能推入 Codex：开发者可把 Codex 连接到 Slack（发消息、读频道）、Figma（读设计稿生成代码）、Notion（读写页面）、Gmail（读邮件、起草回复）等日常工具，无需手动配置。插件在 Codex 启动时自动同步，通过 `/plugins` 命令管理，可在终端界面直接安装卸载并内置鉴权。3 月 27 日 OpenAI 又发布一键式实战用例画廊（构建 iOS 应用、数据集分析、报告与演示生成），Codex v0.117.0 更新日志披露了提示词中提及插件等技术细节。
- **为什么重要：** 这是 OpenAI 编程智能体从"终端里的模型"走向"办公工作流节点"的关键一步：插件生态让 Codex 能直接读写协作工具与设计系统，智能体的价值从代码生成扩展到跨系统任务执行。结合本周曝光的内部备忘录（将 ChatGPT、Codex 与 Atlas 浏览器三合一为桌面超级 App）以及 3 月 19 日对 Python 工具链公司 Astral（uv、Ruff、ty）的闪电收购，OpenAI 正在把开发者工具链、桌面入口与 Agent 能力收拢为一体化矩阵。
- **关键细节：** Anthropic 于 3 月 26 日在工程博客公开 Claude Code 自动模式（auto mode）的设计：针对"93% 的权限请求都会被用户批准"的审批疲劳问题，用两层分类器（输入层探测工具输出中的提示注入，输出层两步评估每个待执行动作）替代人工审批，按风险分三档处理；完整流水线误报率仅 0.4%，漏报率 17%。Claude Code v2.1.84/2.1.85（3 月 26-27 日）新增 Windows PowerShell 原生工具预览与钩子条件字段。

### 6. [重要] [AI 编程工具] GitHub Copilot 支持合并冲突自动解决与智能体会话可视化
- **发生了什么：** 3 月 26 日，GitHub 上线两项 Copilot 重大更新：其一，在 Pull Request 评论中 `@copilot` 即可要求智能体解决合并冲突——它在云环境中工作，解决冲突后验证构建与测试通过再推送变更，所有付费 Copilot 计划可用（Business/Enterprise 需管理员启用）；其二，Issues 与 Projects 中新增智能体活动可视化，当 Copilot、Claude、Codex 等代码智能体被指派到 issue 时，其会话在侧栏实时显示排队、运行中、等待审查、已完成等状态，并可在 Projects 表格与看板视图中展示。此前 3 月 25-26 日还发布了全新 Pull Requests 仪表盘公开预览（集中管理待审查、待修复、可合并的 PR）与 Copilot for Jira 增强（在 Jira 中直接选择模型、工单号自动写入 PR 标题与分支名、通过 Atlassian MCP 服务器访问 Confluence）。
- **为什么重要：** GitHub 正在把"多智能体协作"变成代码托管平台的原生基础设施：合并冲突这类最消耗人类注意力的脏活被交给云端智能体，而跨 Copilot、Claude、Codex 的会话状态统一可视化，解决了团队"不知道智能体在干什么"的信任瓶颈。这实际是把智能体当作一类正式的员工角色纳入研发管理流程。
- **关键细节：** GitHub 3 月 changelog 还预告了 Copilot 中 Claude Sonnet 4 模型的弃用安排；VS Code 已转向每周稳定版发布节奏（v1.111-v1.115 覆盖 3 月至 4 月初）。
- **来源：** https://github.blog/changelog/2026-03-26-ask-copilot-to-resolve-merge-conflicts-on-pull-requests/ ；https://github.blog/changelog/2026-03-26-agent-activity-in-github-issues-and-projects/ ；https://github.blog/changelog/month/03-2026/

### 9. [一般] [政策监管] 白宫《国家 AI 政策框架》发酵：主张联邦优先、轻触式监管
- **发生了什么：** 白宫于 3 月 20 日发布《国家 AI 政策框架：给国会的立法建议》（约 4 页、不具约束力），建议国会采取轻触式、分行业的监管路径，不新设统一监管机构、不做风险分级，核心诉求是以联邦立法优先（preemption）取代 50 个州各自为政的 AI 法规。白宫 AI 事务负责人戴维·萨克斯称此举是为了应对"日益混乱的州级监管制度可能扼杀创新、危及美国在 AI 竞赛中的领先地位"。本周（3 月 23 日前后）该框架持续占据行业议程，围绕联邦优先与州权、资本角力的争论发酵，多家机构发布事实核查与解读。
- **为什么重要：** 该框架与欧盟 AI Act 形成鲜明对照：一个拒绝横向监管与风险分级、押注创新与竞争力，一个坚持基于风险的全面立法。美国若以联邦优先压制州法，将实质决定企业合规成本的地理分布，也影响跨国 AI 公司的全球合规架构选择。
- **关键细节：** 复旦大学全球公共政策研究院等机构本周发布专题解读，指出框架背后是联邦与州、创新与问责之间的权力博弈。

### 10. [一般] [开源模型] 语音模型开源竞赛：Cohere Transcribe 登顶 ASR 榜、Mistral Voxtral TTS 开源权重
- **发生了什么：** 3 月 26 日，Cohere 发布首个自动语音识别模型 Cohere Transcribe，以 Apache 2.0 开源，采用 20 亿参数 Fast-Conformer 编码器-解码器架构（90% 以上参数集中在编码器），基于 50 万小时音频-转录对训练，英文平均词错误率 5.42%，立即登顶 Hugging Face Open ASR 英文榜首（对比：Whisper Large v3 为 7.44%），推理速度较同规模竞品快 3 倍，支持包括中文、日语、韩语在内的 14 种语言。3 月 23 日 Mistral 发布首个开放权重 TTS 模型 Voxtral TTS（模型代号 voxtral-tts-2603），支持 9 种语言，典型配置下延迟 70 毫秒，仅凭 3 秒参考音频即可克隆声音，宣称自然度超过 ElevenLabs Flash v2.5、与 ElevenLabs v3 打平；权重以 Creative Commons 许可发布于 Hugging Face，API 定价 0.016 美元/千字符。
- **为什么重要：** 语音识别与语音合成的开源基线在一周内被连续抬高，专业级语音能力的获取成本急剧下降。对开发者而言，"转写用 Cohere、合成为 Voxtral、实时对话用 Gemini Flash Live"正在形成一条全开源或低价的语音栈路径，压缩闭源语音 API 厂商的定价空间。
- **关键细节：** Cohere 提示 Transcribe 不适用于语码转换场景，建议配合 VAD 过滤；Voxtral TTS 可运行于主流笔记本、中端 GPU 或高端移动设备。
