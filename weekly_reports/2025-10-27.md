## 二、本周重要事件

### 1. [重大] [公司治理] 微软与 OpenAI 签署新最终协议，OpenAI 完成公益公司（PBC）资本重组

- **发生了什么：** 10 月 28 日，微软与 OpenAI 发布联合声明宣布签署一项新的最终协议：微软支持 OpenAI 董事会推进组建公益公司（Public Benefit Corporation）并完成资本重组。OpenAI 同日更新"我们的结构"页面：非营利主体更名为 OpenAI 基金会，营利主体成为 OpenAI Group PBC，基金会继续控制集团。资本重组后，微软对 OpenAI Group PBC 的投资估值约 1,350 亿美元，按转换后摊薄口径约占 27%（覆盖员工、投资者与 OpenAI 基金会等全体所有者）；微软于 10 月 29 日向 SEC 提交 8-K 文件披露该协议。
- **为什么重要：** 这解决了 2023 年以来悬而未决的 OpenAI 治理结构问题，为其后续大规模融资、上市预期与"算力长约"提供了稳定的公司载体；微软约 1,350 亿美元的持股首次以明确数字"入账"，双方关系从"独家云与知识产权绑定"转向"股东加伙伴"的双层结构。作为参照，OpenAI 强调 PBC 不同于传统公司，负有推进既定使命并兼顾全体利益相关者义务，这是前沿实验室商业化路径的第一个完整样本。
- **关键细节：** 联合声明称新协议"巩固合作关系，为双方长期成功奠定基础"；OpenAI 页面明确 PBC 须使"使命与商业成功共同前进"；新华社 11 月 2 日的 10 月全球 AI 综述将此事列为当月产业竞合的标志性事件之一。

### 2. [重大] [芯片算力] 英伟达 GTC 华盛顿大会：Vera Rubin 首次亮相，多吉瓦国家算力蓝图落地

- **发生了什么：** 10 月 27 日至 29 日，英伟达首次在华盛顿特区举行 GTC 大会。10 月 28 日，CEO 黄仁勋公开展示下一代 Vera Rubin 超级芯片；英伟达宣布在弗吉尼亚州建设 AI 工厂研究中心，部署首批 Vera Rubin 基础设施，并发布基于 Omniverse DSX 的跨代际、吉瓦级数据中心建设蓝图。同日，英伟达与甲骨文宣布把 OCI Supercluster 以 Vera Rubin NVL72 扩展至多吉瓦规模，Vera CPU 与 Vera Rubin NVL72 在 OCI 正式可用；英伟达、甲骨文与美国能源部宣布在阿贡国家实验室建设美国最大的 AI 超算（10 万颗 Blackwell GPU）；洛斯阿拉莫斯国家实验室宣布选用 Vera Rubin 平台与 Quantum-X800 InfiniBand。
- **为什么重要：** 在 OpenAI 先后与 AMD、博通锁定 16 吉瓦非英伟达算力的背景下，英伟达用"国家实验室 + 头部云厂商 + 自建 AI 工厂研究中心"的组合正面回击"需求不可持续"与"客户流失"质疑：Vera Rubin 从路线图走向实际部署，且把 AI 基建与美国科研、能源战略直接绑定，"吉瓦计价"的算力军备竞赛获得政府侧背书。
- **关键细节：** 能源部项目由黄仁勋与能源部长 Chris Wright 共同宣布，被描述为"开启智能体 AI 驱动科研的时代"；Omniverse DSX 蓝图定位为可复用的吉瓦级建设模板；中文媒体梳理显示 Vera Rubin 于当地时间 10 月 28 日在 GTC 2025 华盛顿大会上首次公开。

### 3. [重大] [开源模型] MiniMax 开源 M2：230B 总参仅 10B 激活，主打 Agent 与代码，价格约为 Claude Sonnet 的 8%

- **发生了什么：** 10 月 27 日，上海大模型公司 MiniMax 正式开源并上线 MiniMax-M2：稀疏 MoE 架构、总参数 230B、每 token 激活约 10B，上下文窗口 204,800 token，采用 MIT 许可，定位为"专为 Agent 和代码而生"的模型。官方称其在 Claude Code、Cursor、Cline、Kilo Code、Droid 等多种编程应用中表现卓越，可稳定规划并执行复杂长链条工具调用，API 价格约为 Claude Sonnet 的 8%、速度约 2 倍，并推出限时免费。
- **为什么重要：** M2 把开源模型的竞争维度从"跑分"推进到"智能体工作流的单位经济性"：10B 激活参数意味着推理成本显著低于同级稠密模型，MIT 协议与低价组合使其成为 Agent 开发者替换闭源模型的高性价比选项；这也是中国开源阵营在 Q4 密集发布期（此前有 GLM-4.6、DeepSeek-V3.2-Exp 等）的又一次"效率路线"输出。
- **关键细节：** 第三方模型库记录其架构为"稀疏 MoE + 交错思考（interleaved thinking）"，是 M1 的继任者；发布后第三方站点统计其在 Artificial Analysis 智能指数中位列开源模型第一；官方同步上线面向 Agent 场景的产品与开发者文档。
- **来源：** https://www.minimaxi.com/blog/minimax-m2 ；https://aiwiki.ai/wiki/minimax_m2 ；https://ai-tldr.dev/models/minimax-m2/

### 4. [重要] [AI 编程工具] GitHub Universe 发布 Agent HQ：一个界面编排 Anthropic、OpenAI、Google、Cognition、xAI 的智能体

- **发生了什么：** 10 月 28 日，GitHub 在 Universe 2025 大会发布 Agent HQ：面向开发者的统一智能体指挥中心，把 Anthropic、OpenAI、Google、Cognition、xAI 等厂商的编码智能体直接接入 GitHub 工作流，实现"任何智能体、任何时间、任何地点"的编排；同期发布重新设计的 Copilot 编码智能体"任务指挥部"（mission control，集中分派、引导与跟踪任务），以及 GitHub Copilot for Linear 公开预览——把 Linear 议题指派给 Copilot 后，它在由 GitHub Actions 驱动的独立临时环境中自主探索代码、修改、跑测试与静态检查，并把进度实时回写 Linear 时间线。
- **为什么重要：** GitHub 正把自己从"代码托管平台"重定位为"多智能体时代的操作系统"：当五家前沿厂商的智能体在同一平台被指派、审计与合并，编程智能体的竞争焦点从 IDE 插件转向"管理、观测与交付"的平台能力，GitHub 借此卡住智能体工作流的中间层。
- **关键细节：** Agent HQ 初期面向 Copilot Pro+ 用户、经 VS Code Insiders 开放，未来数月逐步扩展至更多智能体与付费订阅者；Copilot for Linear 中智能体在临时开发环境异步运行并自动创建草稿 PR；Azure 韩国技术博客将 Agent HQ 概括为"在一处管理并协同多家 AI 智能体的观测中心"。
- **来源：** https://github.blog/news-insights/company-news/welcome-home-agents/ ；https://github.blog/changelog/month/10-2025/ ；https://github.blog/changelog/2025-10-28-github-copilot-for-linear-available-in-public-preview/ ；https://www.testingcatalog.com/github-unveils-agent-hq-for-ai-coding-agents/

### 5. [重要] [AI 编程工具] Cursor 2.0 发布：自研 agentic 编码模型 Composer，最多 8 个智能体并行

- **发生了什么：** 10 月 29 日，Anysphere 发布 Cursor 2.0 及其首个自研编程模型 Composer。官方称 Composer 是"同等智能水平下快 4 倍"的前沿模型，专为低延迟 agentic 编码打造，多数回合可在 30 秒内完成，训练时配备了包括全代码库语义搜索在内的工具集；2.0 的新编辑器支持多智能体并行管理——同一条提示最多可同时运行 8 个代理，侧边栏集中展示各代理与执行计划。
- **为什么重要：** IDE 厂商自研模型标志着编程智能体竞争进入"模型 + 工具链 + 界面"全栈垂直整合阶段：低延迟的智能体循环取代单次补全成为核心体验指标，Cursor 用自研模型摆脱对第三方 API 的成本与迭代依赖，与 Cognition（SWE 系列）、Windsurf 等"垂直模型"路线正面交锋。
- **关键细节：** 官方 changelog 将 2.0 两大更新概括为"全新代码模型与 Agent 界面"；博客强调早期测试者"对多步编码任务信任 Composer"；语义搜索等工具能力在训练阶段直接内置。
- **来源：** https://cursor.com/changelog/2-0 ；https://cursor.com/blog/2-0

### 6. [重要] [芯片算力] 高通发布 AI200/AI250 机架级推理方案，Humain 承诺 200 兆瓦订单

- **发生了什么：** 10 月 28 日，高通宣布推出面向数据中心的下一代 AI 推理优化方案：基于 AI200 与 AI250 芯片的加速卡与机架。AI200 每卡支持 768GB LPDDR 内存、单机架液冷、机架级功耗 160 千瓦，可承载最高约 10 万亿参数模型的推理；AI250 引入近存计算架构，有效内存带宽提升 10 倍以上、功耗显著降低，支持分离式推理。两者均配备完整软件栈、兼容主流框架并支持 Hugging Face 模型一键部署；AI200 预计 2026 年商用、AI250 预计 2027 年商用，并确立"每年一代"的数据中心路线图。同日，高通与沙特 AI 公司 Humain 宣布合作，后者目标自 2026 年起部署 200 兆瓦的 AI200/AI250 机架，在沙特及全球提供推理服务。
- **为什么重要：** 高通以 NPU 技术切入数据中心推理市场，为"后英伟达时代"的推理层再添一家重量级供应商；"每美元每瓦性能 + 低成本大容量 LPDDR"的 TCO 叙事直指推理成本痛点，而首个大客户是中东主权 AI 公司，印证主权采购正成为新芯片平台冷启动的关键渠道。
- **关键细节：** 官方新闻稿点名 AI250 将带来"代际级"效率跃升；软件栈覆盖从应用层到系统软件层，支持分离式服务（disaggregated serving）等推理优化技术；Humain 合作强调"面向全球推理"的定位。

- **发生了什么：** 10 月 28 日，《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》全文对外发布。"深入推进数字中国建设"一节提出：加快人工智能等数智技术创新，突破基础理论和核心技术，强化算力、算法、数据等高效供给；全面实施"人工智能+"行动，以人工智能引领科研范式变革，加强人工智能同产业发展、文化建设、民生保障、社会治理相结合，抢占人工智能产业应用制高点，全方位赋能千行百业；同时要求加强人工智能治理，完善相关法律法规、政策制度、应用规范、伦理准则。

## 四、本周趋势分析

1. 算力竞争"电力化"：从英伟达的吉瓦蓝图到谷歌重启核电站，电力采购与并网时间表（2029 年量级）开始决定 AI 基建节奏，"每瓦性能"与"每瓦收入"将成为 2026 年芯片与云厂商的核心指标。

3. 开源模型的竞争单位从参数转向"单位任务成本"：MiniMax-M2 的 10B 激活 + MIT + 低价组合，配合 Fireworks 等推理平台的资本化，开源生态的商业闭环从"下载量"走向"每百万 token 毛利"。
4. 主权 AI 进入平台化阶段：Humain 以操作系统、上市计划与多供应商协议构建完整叙事，预计更多国家将以"主权采购 + 本土平台"参与全球算力再平衡，芯片厂商的冷启动渠道随之多元化。
