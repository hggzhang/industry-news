## 二、本周重要事件

### 1. [重大] [大模型] DeepSeek-V3.1 发布并开源：混合推理架构，主打 Agent 能力
- **发生了什么：** 8 月 19 日，DeepSeek 线上模型版本升级至 V3.1 并在 Hugging Face 开源，上下文扩展至 128K；8 月 21 日官方正式发布 DeepSeek-V3.1，称其为"迈向智能体时代的第一步"。新版本带来三大变化：混合推理架构（一个模型同时支持思考与非思考模式，可在对话中切换）、更高的思考效率（V3.1-Think 相比 R1-0528 用更短时间给出答案）、通过 Post-Training 优化显著强化的工具调用与多步 Agent 任务能力。
- **为什么重要：** 这是 DeepSeek 自 R1 之后最重要的架构迭代：把"思考模型"与"指令模型"合并为单一模型，用户按任务复杂度切换模式，兼顾成本与能力；同时官方罕见地上调了 API 价格，说明 DeepSeek 开始用能力溢价替代单纯低价，开源模型的商业模式出现转向。对 Agent 开发者的针对性优化，也意味着中国开源阵营正面进入智能体基础设施竞争。
- **关键细节：** 官方公告同时提到对国产芯片（昇腾等）适配的推进；媒体评价"未见期待中的 R2，但 V3.1 是 Agent 方向的第一步"。V3.1 在多个第三方榜单上思考模式表现强于 R1-0528，非思考模式对齐 V3 并有所提升。
- **来源：** https://api-docs.deepseek.com/zh-cn/news/news250821/ ；https://m.36kr.com/p/3433792896142978 ；https://m.yicai.com/news/102789885.html

### 2. [重要] [开源模型] 字节跳动深夜开源 Seed-OSS-36B：512K 上下文、Apache-2.0
- **发生了什么：** 8 月 20 日夜间至 21 日，字节跳动 Seed 团队在 Hugging Face 与 GitHub 发布开源语言模型系列 Seed-OSS-36B，含三个版本：Seed-OSS-36B-Base（含合成数据）、Seed-OSS-36B-Base-woSyn（不含合成数据）与 Seed-OSS-36B-Instruct，全部采用 Apache-2.0 许可，可免费商用。模型使用 12T tokens 训练，支持 512K 原生长上下文与"思考预算"机制。
- **为什么重要：** 这是字节跳动首次向开源社区释放 36B 级模型，与 OpenAI 的 gpt-oss 策略类似：不开源商业主力豆包，而是用专门版本换取开发者生态与社区影响力。512K 上下文与长上下文基准 SOTA 直接对标主流模型的四倍长度，为长文档、Agent 场景提供了新的高性价比选择。
- **关键细节：** 官方博客标注日期为 2025-08-21；提供含/不含合成数据两个 Base 版本的设计，被视为对学术界的友好安排（可复现纯真实数据训练效果）。火山引擎同步提供部署方案。
- **来源：** https://seed.bytedance.com/zh/blog/seed-oss-open-source-models-release ；https://tech.ifeng.com/c/8lze1Pt1UIu ；https://www.thepaper.cn/newsDetail_forward_31453676

### 3. [重要] [芯片算力] 英伟达被曝通知供应商全面停产 H20 中国特供芯片
- **发生了什么：** 8 月 22 日前后，媒体报道英伟达已通知三星、安靠科技等供应商停止 H20 芯片的相关生产。此前 7 月美国放开 H20 对华出口许可，但 8 月初美方又要求从 H20 对华销售收入中抽取 15% 以上，中国客户采购意愿骤降；英伟达二季度财报显示对华 H20 销售额为零，许可放开后仅录得约 6000 万美元收入。

### 4. [重要] [开源模型] 马斯克宣布 Grok 2 开源，权重上线 Hugging Face
- **发生了什么：** 8 月 24 日（周末），马斯克在 X 平台宣布 Grok 模型开源，权重发布到 Hugging Face。智东西等中文媒体核实指出：马斯克推文写的是"Grok 2.5"，实际开源的是 Grok 2（约 3000 亿参数 MoE 模型），且许可证限制商用、也不允许用于训练其他模型；马斯克同时预告 Grok 3 将在半年后开源。
- **为什么重要：** xAI 加入前沿权重开源行列，改变"开源=中国厂商攻势"的市场印象；但受限许可证引发的"半开源"争议（36 氪标题称"开源了，但好像又没完全开"）说明大厂开源更多是生态卡位而非彻底开放，与 DeepSeek、字节的 Apache-2.0 全开放形成对照。
- **关键细节：** 这是 xAI 继 Grok 1 之后第二次释出权重；社区可下载推理但不可蒸馏或再训练。InfoQ 在 8 月 24 日 AI 周报中以"马斯克刚刚开源 Grok 2.5"为题报道。

## 三、本周行业变化总结

本周的行业重心明显向"开源与定价"倾斜：DeepSeek-V3.1 涨价开源、字节 Apache-2.0 全开放、xAI 限制性开源，三种开源姿态同周出现，说明开源已从"慈善"变成有意识的商业策略。硬件与组织层面同时出现收缩信号：英伟达 H20 停产、华为裁撤盘古部门、Altman 承认泡沫，狂热叙事下进入结构性调整。产品侧，教育（Grammarly Agent、Google Flow 运营）与语音（Fun-ASR）等垂直场景加速 Agent 化。中国厂商在模型、音视频生成两条线同时以低价放量，全球 AI 竞争的价格维度进一步尖锐化。

## 四、本周趋势分析

1. **开源分层：** 全开放（DeepSeek、字节 Apache-2.0）、限制商用（Grok 2）、不开源商业主力（OpenAI 模式）三种策略并存，开源许可证本身正在成为竞争武器；"开源+涨价"组合显示头部开源模型开始追求能力定价而非流量定价。
2. **混合推理成为标准形态：** DeepSeek-V3.1 的 Think/Non-Think 切换与英伟达 Nemotron 的推理开关在同一周出现，"思考预算可控"从论文概念变成产品标配，模型选择逻辑从"选模型"转向"选推理档位"。
3. **特供芯片模式终结，国产替代窗口打开：** H20 停产与 15% 分成政策叠加，中国客户转向国产算力的确定性提高，华为"弃模型、保算力"的组织调整正是对这一窗口的战略卡位。
4. **大厂 AI 组织进入收缩周期：** 华为云数十部门撤销、盘古团队裁撤，说明通用大模型自研的边际价值在部分大厂内部被否定，资源向算力与场景聚焦将成为更多企业的选择。

## 五、值得尝试的工具与工作流

- **DeepSeek-V3.1（API/网页）：** 开发者可用 Think/Non-Think 切换做成本分级：简单抽取走非思考模式，Agent 工具调用与多步任务走思考模式，对比旧 R1 可显著降低时延。
- **Seed-OSS-36B：** 需要长文档（512K）+可商用许可的中小团队可直接部署，含/不含合成数据的 Base 双版本适合做继续预训练实验。
