## 二、本周重要事件

### 1. [重大] [芯片算力] AMD 与 OpenAI 签署 6 吉瓦 GPU 供应协议，认股权证绑定约 10% 股权

- **发生了什么：** 10 月 6 日，AMD 与 OpenAI 联合宣布战略合作：OpenAI 将在其下一代 AI 基础设施中部署总计 6 吉瓦的 AMD Instinct 系列 GPU，跨越多代产品；首批 1 吉瓦采用 MI450 系列 GPU，计划于 2026 年下半年开始部署。同日 AMD 向美国 SEC 提交的 8-K 文件披露，AMD 已于 10 月 5 日向 OpenAI OpCo, LLC 发行最多可购买 1.6 亿股 AMD 普通股的认股权证，行权价每股 0.01 美元，分阶段归属，与采购里程碑挂钩。
- **为什么重要：** 这是大模型巨头首次以"巨额算力长约 + 股权期权"双重方式与英伟达之外的 GPU 供应商深度绑定。若认股权证全部行使，OpenAI 将持有 AMD 约 10% 的股份，双方形成利益共同体。对行业而言，它意味着前沿模型训练的算力采购正在从"单一大买家对英伟达"转向多供应商、跨代际、以年为单位的战略锁定，算力供给方与模型方的关系被重新定义。
- **关键细节：** 协议覆盖"多代"Instinct GPU，说明 OpenAI 锁定的不只是 2026 年的 MI450，还包括后续迭代；首批 1 吉瓦部署时间定在 2026 年下半年，与 OpenAI 的 Stargate 等数据中心建设节奏相匹配；8-K 文件明确认股权证的归属与 OpenAI 实际采购 AMD 产品的规模挂钩。
- **来源：** https://newsroom.amd.com/news/amd-and-openai-announce-strategic-partnership-to-d/ ；https://ir.amd.com/financial-information/sec-filings/content/0001193125-25-230895/d28189d8k.htm ；https://view.inews.qq.com/k/20251013A08G2L00

### 2. [重大] [大模型发布] OpenAI DevDay 2025：GPT-5 Pro 进入 API，新一代实时语音模型与 Sora 2 开发者能力同场发布

- **发生了什么：** 10 月 6 日，OpenAI 年度开发者大会 DevDay 2025 举行，集中发布面向开发者与企业的一揽子升级：旗舰推理模型 GPT-5 Pro 首次通过 API 提供；发布新一代实时语音模型；Sora 2 视频/音频生成能力向开发者开放；同时推出 AgentKit、ChatKit、Apps SDK 等平台组件。
- **为什么重要：** DevDay 是 OpenAI 把前沿模型能力"平台化"的节点：GPT-5 Pro 以更高单价服务对推理质量最敏感的工作负载，语音与视频能力进入 API 意味着实时语音助手、视频生成类应用可以在生产环境中直接调用。结合本周的 Apps SDK，OpenAI 正在把 ChatGPT 的 8 亿级周活流量变成开发者分发入口，模型公司的角色从"卖 API"扩展为"运营平台"。
- **关键细节：** 社区研究简报显示，GPT-5 Pro 提供约 40 万 token 的上下文窗口、最高约 27.2 万 token 的输出，输入定价约 15 美元/百万 token，定位明显高于标准 GPT-5；本次发布被多家媒体概括为"从旗舰模型到开发者工具再到商业合作的全面升级"。
- **来源：** https://intuitionlabs.ai/pdfs/openai-devday-2025-gpt-5-pro-sora-2-platform-updates.pdf ；https://tomorrowunveiled.com/wp-content/uploads/2025/10/Episode_-_AI_Unveiled-_1007_-_Perplexity.pdf ；https://ai-weekly.ai/newsletter-10-07-2025/

### 3. [重要] [Agent 平台] OpenAI 推出 AgentKit：可视化工作流、ChatKit、Evals 与 Traces 一体化

- **发生了什么：** 10 月 6 日，OpenAI 宣布推出 AgentKit，面向开发者与企业提供构建、部署和优化智能体的完整工具集，核心包括可视化设计与版本化管理的 Agent Builder、可嵌入产品的对话式界面工具包 ChatKit，以及扩展后的 Evals 能力（数据集、Trace 分级、自动提示词优化、对第三方模型的支持）与 Traces 调试工具。
- **为什么重要：** 此前构建生产级智能体需要在编排框架、自建连接器、手工评测管线和前端开发之间反复横跳，往往消耗数周。AgentKit 把这条链路收拢为官方一体化方案，配合 Responses API 与 Agents SDK 的既有布局，OpenAI 正在把"智能体基础设施"标准化，压低中小团队进入 Agent 开发的门槛，同时增强对开发者生态的锁定。
- **关键细节：** OpenAI 强调 Agent Builder 支持可视化工作流设计与嵌入式的 agentic UI；Evals 新增对第三方模型的支持，意味着评测体系不再只服务于 OpenAI 自家模型；Traces 用于对多步智能体执行过程做观测与调试。
- **来源：** https://openai.com/blog/introducing-agentkit

### 4. [重要] [AI 产品] ChatGPT 引入"Apps"与 Apps SDK：可对话的应用形态登场

- **发生了什么：** 10 月 6 日，OpenAI 发布 Apps in ChatGPT 及配套的 Apps SDK，允许开发者构建可以直接在 ChatGPT 内使用、可对话的应用，用户无需离开对话界面即可完成原本需要独立 App 的任务。该功能以研究预览形式启动，面向开发者开放构建工具。
- **为什么重要：** 这是 ChatGPT 从"助手"向"分发平台"转型的关键一步：当应用可以直接嵌入对话界面，ChatGPT 的超大流量将重新分配开发者入口，浏览器插件、独立 App 与超级应用之间的边界被进一步模糊。对创业者而言，"在 ChatGPT 内被调用"可能成为与"上架应用商店"同等量级的分发渠道。
- **关键细节：** 官方将 Apps SDK 定位为"新一代可对话应用"的开发工具，并说明现有插件与工作区场景将由 ChatGPT Work 与商业解决方案承接，显示 OpenAI 在同步收敛历史产品线。
- **来源：** https://openai.com/index/introducing-apps-in-chatgpt/

### 5. [重要] [AIGC 视频] Sora 2 独立 App 邀请制持续放量，官方称将快速扩展至更多国家

- **发生了什么：** OpenAI 于 9 月 30 日发布 Sora 2 及独立社交应用 Sora，用户可用文字提示和图像生成带声音的视频并与朋友分享。本周该应用在美国、加拿大继续以邀请制放量：iOS 用户可先下载应用并登记等待账号开通，获邀后可同时通过 sora.com 使用；官方明确"初始在美加推出，并计划快速扩展至更多国家"。截至 10 月初该应用仍仅限 iOS 平台。
- **为什么重要：** Sora 2 把视频生成能力包装成社交产品，是"AI 原生内容社区"的第一次大规模实验：生成即分享、分享即传播的闭环让视频模型的竞争从单纯画质转向内容生态与分发。邀请制放量节奏也显示 OpenAI 在算力成本、内容安全与增长之间做平衡。
- **关键细节：** Sora 2 系统卡强调相比前代在物理准确性、画面真实感与同步音频上的提升；App Store 描述称其为"把文字提示和图像转化为带声音视频"的创意应用；发布初期仅 iOS、仅美加，安卓与更多地区为后续计划。
- **来源：** https://openai.com/index/sora-2/ ；https://m.baike.com/wiki/Sora/7556812375417651215 ；https://www.infobae.com/tecno/2025-10-01/openai-presenta-sora-2-y-anuncia-su-primera-app-para-crear-videos-con-inteligencia-artificial/

### 6. [一般] [开源模型] DeepSeek-OCR 开源："光学上下文压缩"新范式引发社区热议

- **发生了什么：** DeepSeek 开源 3B 参数的 OCR 模型 DeepSeek-OCR（DeepEncoder + 3B MoE 解码器），论文《Contexts Optical Compression》（arXiv:2510.18234）于 10 月初挂出，模型权重同步上线 Hugging Face 与 GitHub。本周 InfoQ 等媒体集中报道，中文技术社区讨论热度持续上升，上线后快速积累下载量与 GitHub Star。
- **为什么重要：** 该工作提出"用视觉模态对长文本做信息压缩"的新范式：将文本渲染为图像后以视觉 token 编码，在 10 倍压缩率下解码精度约 97%，20 倍压缩率下仍保持约 60% 准确率。如果路线可行，长上下文推理的 token 成本结构将被改写，为超长文档处理提供全新思路。
- **关键细节：** 模型以 MIT 类宽松协议开源；核心思路是让视觉 token 高效承载文本信息，社区讨论焦点已从实现细节上升到"视觉即信息压缩"的范式争论。
- **来源：** https://arxiv.org/abs/2510.18234 ；https://www.infoq.com/news/2025/10/deepseek-ocr/ ；https://juejin.cn/post/7562942552242405411

### 7. [一般] [开源模型] IBM Granite 4.0 上架 Docker Hub，主打超高效混合架构

- **发生了什么：** 10 月 6 日，Docker 宣布 IBM 最新开源的 Granite 4.0 语言模型进入 Docker Hub 模型目录，开发者可通过 Docker Model Runner 在本地几分钟内完成拉取与运行；Granite 4.0 采用 Mamba/Transformer 混合架构，以 Apache 2.0 协议开源，并宣称是全球首批获得 ISO 42001 认证且经加密签名的开放模型。
- **为什么重要：** "开源企业模型 + 一键本地运行"的组合降低了合规敏感行业试用开源模型的心理与工程门槛；混合架构显著压缩显存需求，使企业可以用更便宜的 GPU 部署同级性能的模型，是本周"算力多元化"叙事在模型侧的呼应。
- **关键细节：** Granite 4.0 家族强调速度、灵活性与成本效益，定位企业级知识工作；除 Docker Hub 外还通过 Dell 等硬件合作伙伴与 watsonx.ai 平台分发。
- **来源：** https://www.docker.com/blog/ibm-granite-4-0-models-now-available-on-docker-hub/ ；https://www.ibm.com/new/announcements/ibm-granite-4-0-hyper-efficient-high-performance-hybrid-models

## 三、本周行业变化总结

本周的主线是"算力政治经济学"与"平台化"。AMD 与 OpenAI 的 6 吉瓦协议把大模型公司的算力承诺从订单升级为股权绑定，供应多元化从口号变成资产负债表事件；OpenAI DevDay 则把模型能力（GPT-5 Pro、语音、Sora 2）与分发能力（Apps SDK、AgentKit）打包成平台，AI 公司的竞争单元正在从"单个模型"转向"模型 + 工具链 + 入口"的组合。与此同时，DeepSeek-OCR 与 Granite 4.0 表明开源阵营在"效率"与"合规"两条差异化路线上继续推进，垂直 AI 融资（Heidi）显示应用层资本化并未因巨头叙事而降温。

## 四、本周趋势分析

1. 算力交易结构金融化：认股权证、分阶段归属、跨代际承诺成为大买家与芯片供应商的标准绑定方式，后续其他模型公司与芯片厂商可能复制该结构。
2. 智能体开发走向"官方套件化"：AgentKit 类工具把编排、评测、观测收进模型厂商的 SDK，第三方编排框架的差异化空间被压缩，竞争转向行业知识与连接器生态。
3. 对话界面成为新的应用分发层：Apps in ChatGPT 与 Sora 社交 App 共同指向一个趋势——超级模型入口开始吸收长尾应用与内容社区的分发权。
4. 效率路线成为开源模型的共同语言：无论是 DeepSeek-OCR 的光学压缩还是 Granite 4.0 的混合架构，都在回答同一问题——如何以更少的显存和 token 成本换取同等能力。

## 五、值得尝试的工具与工作流

- AgentKit（Agent Builder + ChatKit + Evals + Traces）：适合已有 Responses API/Agents SDK 基础的团队，把智能体的版本管理、评测与观测一次补齐。
- Apps SDK：若你的产品有明确的任务型场景（预订、检索、生成类工具），可提前以研究预览形式接入，抢占 ChatGPT 内早期分发位。
- Docker Model Runner + Granite 4.0：适合需要本地验证企业模型、又受限于显存成本的团队，几分钟即可跑通原型。
- DeepSeek-OCR：适合对超长文档处理有刚需的开发者实验"视觉压缩上下文"的可行性，关注其在 10 倍压缩率下的精度表现。

## 六、下周值得关注的事项

- ChatGPT Apps 研究预览的首批接入方与开放节奏，可能决定"对话内应用"生态的第一批赢家。
