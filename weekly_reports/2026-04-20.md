# AI 周报｜2026-04-20 至 2026-04-26

## 一、本周核心结论

1. 前沿模型进入"月度迭代"节奏：OpenAI 在 GPT-5.4 上线约六周后发布全新基座 GPT-5.5，重新夺回 Artificial Analysis 智能指数榜首；DeepSeek-V4、Kimi K2.6、Qwen 3.6 Max 等国产模型在五个工作日内密集发布。
2. 开源模型首次以"前沿级能力 + 六分之一价格"正面冲击闭源旗舰：DeepSeek-V4-Pro 的 SWE-bench Verified 得分距 Claude Opus 4.6 仅 0.2 个百分点，输出价格却只有 GPT-5.5 的约十分之一。
3. 算力与资本深度绑定：Anthropic 一周内获得 Google 最高 400 亿美元与亚马逊最高 250 亿美元两笔注资承诺，并锁定至少 10GW 新增算力；Bezos 的 Project Prometheus 完成 100 亿美元融资。
4. 产品形态从"对话 Chatbot"整体切换为"自主智能体 Agent"：GPT-5.5 被定义为"一种新的电脑工作方式"，Google 把企业入口直接做成 Agent 平台，Kimi K2.6 主打 300 个子 Agent 群体协作。

## 二、本周重要事件

### 1. [重大] [大模型] OpenAI 发布 GPT-5.5：GPT-4.5 以来首个全新重训基座模型

- **发生了什么：** 4 月 23 日，OpenAI 正式发布 GPT-5.5（内部代号 "Spud"），这是自 GPT-4.5 以来第一个完全重新训练的基座模型，此前的迭代均为同一架构上的增量更新。4 月 24 日起向 API 与 Pro、Business、Enterprise 级开发者开放 GPT-5.5 与 GPT-5.5 Pro 两档规格，ChatGPT 端面向 Plus 及以上付费用户全面铺开，并同步接入 Codex 体系。
- **为什么重要：** GPT-5.5 在 Artificial Analysis 智能指数上拿到 60 分，创纪录并让 OpenAI 重返榜首；OSWorld-Verified（自主操作系统导航与 UI 操作）达 78.7%，Terminal-Bench 2.0 达 82.7%。OpenAI 官方将其定位为"一种新的电脑工作方式"，即能在企业工作流中自主完成代码编写调试、在线研究、数据分析、文档生成与跨工具操作直至任务结束的端到端智能体，标志着头部厂商正式把旗舰产品形态从对话切换到智能体计算。
- **关键细节：** 模型原生全模态（文本、图像、音频、视频统一架构），上下文窗口 100 万 token，在 512K–1M 长度上的 MRCR v2 得分 74%（GPT-5.4 为 36.6%）。API 定价每百万输入 token 5 美元、输出 30 美元，GPT-5.5 Pro 为 30/180 美元，较 GPT-5.4 基础档位约翻倍；OpenAI 称单任务实际消耗 token 数下降约 40%，可部分抵消涨价。发布距 GPT-5.4 上线仅约六周，是 GPT-5 系列最快的一次迭代。
- **来源：** https://mml-studio.com/blog/ai-weekly-april-20-26-2026/ ；https://hub.baai.ac.cn/view/54367 ；https://galileo14.com/en/news/ai-news-april-2026/

### 2. [重大] [开源模型] DeepSeek-V4 预览版上线并同步开源：百万上下文、价格仅为闭源旗舰零头

- **发生了什么：** 4 月 24 日，深度求索（DeepSeek）发布新一代 DeepSeek-V4 预览版并同步开源，包含 V4-Pro（总参数 1.6 万亿、单 token 激活 490 亿、MoE 架构）与 V4-Flash（总参数 284B、激活 130B）两个规格，均原生支持 100 万 token 超长上下文。用户可即刻在 chat.deepseek.com 与官方 App 对话使用。这是 DeepSeek 自 2025 年初 V3 系列引爆全球后时隔约一年的主力模型换代。
- **为什么重要：** V4-Pro 在 SWE-bench Verified 达 80.6%，距 Claude Opus 4.6 仅 0.2 个百分点；Terminal-Bench 2.0 上以 67.9% 领先 Claude（65.4%），LiveCodeBench 93.5% 对 88.8%。输出定价 V4-Pro 每百万 token 3.48 美元、V4-Flash 仅 0.28 美元，约为 GPT-5.5（30 美元）的十分之一、Opus 4.7（25 美元）的七分之一。对占绝大多数的成本敏感型生产负载，开源前沿级模型将直接成为默认选项。更具产业意义的是，技术报告披露其细粒度专家并行方案已在英伟达 GPU 与华为昇腾 NPU 双平台完成全栈验证，端到端推理加速 1.50–1.73 倍，这是国产前沿大模型首次在国产算力平台上达到与国际主流硬件相当的生产可用性能；华为同日确认 Ascend 950 支持 V4 部署。
- **关键细节：** 官方说明受限于高端算力规模，V4-Pro 对外服务吞吐短期受限，优先面向企业级用户与战略合作伙伴开放；预计 2026 年下半年昇腾 950 超节点批量上市后价格将大幅下调并向开发者社区更大规模开放。API 文档同时公告旧模型 deepseek-chat 与 deepseek-reasoner 将于 7 月 24 日退役，当前路由至 deepseek-v4-flash。
- **来源：** https://www.deepseek.com/en/news/v4-preview/ ；https://digital.gmw.cn/2026-04/24/content_38729818.htm ；https://api-docs.deepseek.com/news/news260424 ；https://hub.baai.ac.cn/view/54367

### 3. [重大] [融资并购] Anthropic 一周内锁定最高 650 亿美元注资与至少 10GW 算力

- **发生了什么：** 4 月 20 日，亚马逊与 Anthropic 宣布扩大合作：在既有 80 亿美元基础上追加最高 250 亿美元投资（部分即付、部分与里程碑挂钩），同时 Anthropic 承诺十年内向 AWS 支出超 1000 亿美元并预留 5GW 新增训练与推理容量。4 月 24 日，Google 母公司 Alphabet 宣布对 Anthropic 迄今最大规模投资：即刻 100 亿美元现金、另有最高 300 亿美元与业绩里程碑挂钩，估值确认在 3500 亿美元水平，并附带未来五年（自 2027 年起）新增 5GW 的 Google Cloud 算力。
- **为什么重要：** 一周之内，Anthropic 从两大云厂商获得合计最高 650 亿美元注资承诺与至少 10GW 新增算力，规模可与 OpenAI 整体算力盘子相当。这印证了 2026 年 AI 竞争的本质：模型估值等于电力与芯片的获取能力。Google 由此形成"自有 Gemini + 持股 Anthropic"的双引擎云战略；背景是 Claude 在企业编码与智能体市场销售领先 Gemini，而 Anthropic 年化经常性收入已在 4 月突破 300 亿美元（较 2025 年底约 90 亿美元增长三倍以上），百万美元级年合同企业客户超过 1000 家。
- **关键细节：** Google 同步扩大与博通（Broadcom）的算力协作以支持 Anthropic 下一代模型训练与推理基础设施；此前博通已向 SEC 提交与 Google 为期五年（至 2031 年）的 TPU 定制供应协议。微软则以累计超 130 亿美元投资与 OpenAI 深度绑定，全球前沿实验室与超大规模云厂商的垂直绑定格局进一步固化。

### 5. [重要] [开源模型] Kimi K2.6 正式上线：12 小时自主执行与 300 个子 Agent 协作

- **发生了什么：** 4 月 20 日至 21 日，月之暗面（Moonshot AI）将 Kimi K2.6 从 Code Preview 分支转为正式可用版本并全平台上线，距其首次公开仅约一周。K2.6 为 1 万亿参数 MoE（激活 32B、384 个专家），原生多模态并支持 INT4 量化，vLLM、OpenRouter、Cloudflare Workers AI、MLX、OpenCode 实现 Day-0 适配。
- **为什么重要：** 其核心定位是"长程自主执行"：支持单次会话 12 小时自主编码、可在数千步操作链上保持目标导向，平台原生支持 300-Agent 级群体协作（Agent Swarm），主控 Agent 可协调多达 300 个子 Agent 并行处理子任务、跨步协调约 4000 步。基准上 HLE（含工具）54.0、SWE-Bench Pro 58.6、SWE-bench Multilingual 76.7、BrowseComp 83.2，为开源模型 SOTA，其中两项超越同期主要闭源旗舰。它与 DeepSeek-V4 在五个工作日内分别从"长程工程执行"与"通用前沿能力"两个方向，把开源智能体可用性推到与美国闭源旗舰相当甚至局部领先的水平。
- **关键细节：** 模型在重构遗留代码、生成全栈应用、跨语言协作等真实工程任务上的可用性显著提升；月之暗面把 12 小时连续执行与 300 子 Agent 协调作为本次发布的核心理念。

### 12. [一般] [安全] MCP 远程代码执行漏洞披露，波及 7000 台公开服务器

- **发生了什么：** 本周 The Hacker News 披露一项 Anthropic 模型上下文协议（MCP）漏洞：特定实现存在缺陷，攻击者可对运行脆弱版本的服务器实施远程代码执行。受影响范围约 7000 台可公开访问的 MCP 服务器，相关包累计下载量超过 1.5 亿次。
- **为什么重要：** MCP 已成为 Agent 连接外部工具的事实标准，其供应链安全直接决定智能体生态的可信度。结合上周 Vercel 因第三方 AI 工具 Context.ai 的 OAuth 应用被劫持而泄露环境变量与 API Key 的事件，"不直接攻击目标、而是经由受信任的 AI 工具依赖链进入"已成为 2026 年 AI 供应链攻击的标准模式。
- **关键细节：** Fitch Ratings 4 月 20 日报告亦警告：防御侧 AI 的快速铺开短期内可能引入新的脆弱面。企业在使用第三方 AI 分析、编码与自动化插件时应审查其 OAuth 授权面与 MCP 服务端暴露情况。

## 四、本周趋势分析

1. **智能体成为旗舰模型的默认叙事。** GPT-5.5 的"新的电脑工作方式"、Kimi K2.6 的 300 子 Agent 协作、Google 的"企业级智能体操作系统"、Claude Code 的云端找虫舰队，四件事在同一周发生并非巧合：行业正把竞争维度从"回答质量"切换到"长程自主执行"，评测重心随之转向 OSWorld、Terminal-Bench、SWE-Bench Pro 等 agentic 基准。
2. **开源前沿化改写定价曲线。** DeepSeek-V4 以约十分之一的输出价格逼近闭源旗舰，且完成昇腾/英伟达双平台生产验证。对高端研究场景闭源旗舰仍有溢价空间，但对占多数的成本驱动型生产负载，开源默认化将倒逼闭源厂商在"降价"与"再涨价换能力"之间做选择——本周 GPT-5.5 选择涨价，赌的是智能体任务省 token 的效率。
3. **算力即估值，电力即护城河。** Anthropic 的 10GW 承诺、Google 的 5GW TPU 协议、微软的澳大利亚数据中心、Meta 的 Graviton 订单表明：模型公司估值越来越由"能拿到多少电和芯片"决定，云厂商与实验室的垂直绑定（微软-OpenAI、亚马逊/Google-Anthropic、华为-DeepSeek）成为结构性格局。
4. **国产算力第一次通过前沿模型的生产级检验。** V4 在昇腾 NPU 上的全栈验证与 Ascend 950 的支持确认，叠加 GLM-5.1 此前用约 10 万张昇腾 910B 完成全流程训练，出口管制对国产前沿训练的约束效果持续减弱。
5. **AI 供应链安全成为新攻击面。** MCP RCE 漏洞与 Vercel/Context.ai OAuth 事件共同说明：Agent 生态的插件、网关与第三方工具依赖链是当前防御最薄弱、攻击回报最高的环节。
