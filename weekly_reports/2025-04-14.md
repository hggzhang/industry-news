# AI 周报｜2025-04-14 至 2025-04-20

**统计周期：** 周一 00:00 至周日 23:59:59（Asia/Shanghai）

## 一、本周核心结论

1. OpenAI 一周内完成"三连发"：4 月 14 日推出主打性价比与 1M 上下文的 GPT-4.1 系列，4 月 16 日发布最强推理模型 o3 与 o4-mini 并附带开源编程代理 Codex CLI，同时宣布逐步下线 GPT-4.5——模型矩阵从"堆料炫技"全面转向"分层定价 + 实用编码"。
2. 编程 Agent 成为本周绝对主线：o3/o4-mini 在 Codeforces、SWE-bench 等编程基准创纪录，Codex CLI 把"终端里的编程代理"变成开源基础设施，直接对标 Claude Code 与 Cursor。
3. 芯片地缘政治再升级：英伟达 4 月 15 日披露 H20 对华出口需"无限期"申请许可证，同时宣布首次在美国本土制造 AI 超级计算机；台积电财报确认 AI 需求让利润创历史新高，"算力主权化"趋势明确。
4. 中国开源模型密集上新：智谱 4 月 14-15 日连发 GLM-4-32B-0414 系列与 GLM-Z1 新品，把"推理 + 自主搜索 + 高速部署"打包开源，进一步挤压闭源小模型市场。
5. 监管侧欧盟出手：欧盟数据保护委员会发布针对大语言模型的隐私风险与缓解措施报告，AI 合规讨论从"训练数据版权"延伸到"推理与部署中的隐私"。

## 二、本周重要事件

### 1. [重大] [大模型发布 / AI 编程] OpenAI 发布 GPT-4.1 系列：1M 上下文、价格远低于 GPT-4.5

- **发生了什么：** 4 月 14 日，OpenAI 在 API 平台一次性上线 GPT-4.1、GPT-4.1 mini 与 GPT-4.1 nano 三款模型。官方称三款模型全面超越 GPT-4o 与 GPT-4o mini，在编程与指令遵循上提升显著，均支持最高 100 万 token 上下文窗口，且以远低于 GPT-4.5 的价格提供相当甚至更好的性能。
- **为什么重要：** GPT-4.1 系列标志着 OpenAI 的产品策略转向：不再用单一旗舰打天下，而是提供"大中小"三档同代模型覆盖成本敏感场景；1M 上下文 + 强编码的组合直接服务 Agent 与代码库分析需求，被普遍视为对 Gemini 2.5 Pro 长上下文优势的正面回应。
- **关键细节：** 官方发布说明称该系列"全面超越 GPT-4o 与 GPT-4o mini"，编程与指令遵循提升"显著"；媒体实测普遍报告其在代码修复与长文档任务中表现稳定；券商行业周报将其列为本周国内外大模型持续迭代的核心事件。
- **来源：** https://pdf.dfcfw.com/pdf/H3_AP202504211659950436_1.pdf ；https://www.52nlp.cn/wp-content/uploads/2025/04/Introducing-GPT-4.1-in-the-API-_-OpenAI-dual.pdf

### 2. [重大] [大模型发布 / AI 编程] OpenAI 发布 o3 与 o4-mini：最强推理模型 + 终端编程代理 Codex CLI

- **发生了什么：** 4 月 16 日，OpenAI 发布 o3（迄今最聪明、能全面调用网页搜索、Python、视觉等工具链的推理模型）与更小更便宜的 o4-mini。官方称两者在 Codeforces、SWE-bench、MMMU 等基准上创下新纪录；同步公布实验性轻量编程代理 Codex CLI（可直接在终端运行、基于 o3/o4-mini 的推理能力），以及由强化学习训练、面向软件工程任务的 Codex 系统。
- **为什么重要：** o3 把"全工具访问"的推理模型推向生产可用，编程基准的突破意味着 AI 处理真实工程任务的能力台阶式提升；Codex CLI 以"终端原生代理"形态入场，直接冲击 Claude Code、Cursor 等编程工具的市场格局，"模型厂商自做 Agent 工具"成为新趋势。
- **关键细节：** o3 与 o4-mini 面向 ChatGPT 付费用户与 API 开放；o4-mini 专为快速、成本友好的场景优化，在数学、编程、视觉任务上性价比突出；官方把 Codex CLI 定位为"在终端机内执行的轻量级编程代理"，直接在用户电脑上工作，未来将支持包括 GPT-4.1 在内的其他 API 模型。
- **来源：** https://openai.com/zh-Hant-HK/index/introducing-o3-and-o4-mini/ ；https://pdf.dfcfw.com/pdf/H3_AP202504211659950436_1.pdf

### 3. [重要] [芯片算力 / 政策监管] 英伟达披露：H20 对华出口需"无限期"申请许可证

- **发生了什么：** 4 月 15 日，英伟达向美国证监会提交文件（8-K）披露：美国政府已通知公司，向中国（含港澳）及 D:5 国家组出口 H20 集成电路、以及达到 H20 内存带宽/互连带宽水平的其他芯片，均需申请许可证且无明确时限。H20 本是英伟达为符合此前出口管制而专门设计的"中国特供"AI 芯片。
- **为什么重要：** 这是美国对华 AI 芯片管制从"性能红线"走向"许可证不确定"的标志性一步：即便合规特供芯片也可能被"无限期"卡住，直接冲击英伟达中国区收入预期，也倒逼中国算力自主替代加速，国内 GPU 与推理芯片板块应声走强。
- **关键细节：** 英伟达在监管文件中表示，美国政府通知"无限期"许可证要求；媒体分析指出 H20 与 A100/H100 系列此前已受出口限制，此次把"特供合规"路线也封死；后续英伟达财报显示该事件导致 H20 需求骤减并计提 45 亿美元库存及相关采购义务减值。
- **来源：** https://www.sec.gov/Archives/edgar/data/1045810/000104581025000082/nvda-20250409.htm ；http://stcn.com/article/detail/1671221.html ；https://m.baike.com/wiki/Nvidia%20H20/7373425412549296154 ；https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-first-quarter-fiscal-2026

### 4. [重要] [芯片算力] 台积电一季度净利润同比大增约 60%，AI 需求驱动业绩全面超预期

- **发生了什么：** 4 月 17 日，台积电发布 2025 年第一季度财报：合并营收新台币 8392.5 亿元（同比增长 41.6%），净利润新台币 3615.6 亿元（同比增长约 60%），每股收益 13.94 新台币（每 ADR 2.12 美元），均创历史同期新高；高性能计算平台营收占比接近六成，成为第一大收入来源。
- **为什么重要：** 作为英伟达、AMD 等 AI 芯片的独家先进制程代工方，台积电财报是全球 AI 算力需求的"风向标"。在 4 月初中美关税升级的背景下，AI 订单未见降温，验证了算力建设的真实景气度，也支撑了"AI 资本开支周期仍在上行"的市场共识。
- **关键细节：** 公司此前 4 月 10 日已公布季度营收快报（同比增长 41.6%，优于彭博分析师预期，见上周周报）；完整财报确认 HPC（高性能计算）已成为第一大收入来源、占比接近六成，智能手机占比约 28%。
- **来源：** https://investor.tsmc.com/english/encrypt/files/encrypt_file/reports/2025-04/6580235c47b7b8f1056b071faa44d958c2c3ba04/1Q25EarningsRelease.pdf ；https://www.stcn.com/article/detail/1824151.html

### 5. [重要] [开源模型] 智谱密集开源 GLM-4-32B-0414 系列与 GLM-Z1 新品，推理速度达 200 tokens/秒

- **发生了什么：** 4 月 14 日，智谱发布新一代 GLM-4-32B-0414 系列（含基座、对话与推理版本），官方称效果比肩 GPT 系列与 DeepSeek-V3/R1；4 月 15 日，智谱一口气上线并开源三款新模型：沉思模型 GLM-Z1-Rumination（边思考边自主搜索完成复杂任务）、推理模型 GLM-Z1-Air、基座模型 GLM-4-Air-0414，并宣布 API 限时免费，商用推理速度达 200 tokens/秒。
- **为什么重要：** 在 Llama 4 因基准争议口碑受损的窗口期，国产开源阵营以"小体积、高速度、真开源"抢占开发者心智；GLM-Z1-Rumination 把"深度思考 + 自主搜索"做成开源模型能力，为构建低成本搜索型 Agent 提供了新底座。
- **关键细节：** GLM-4-32B-0414 支持本地部署，部分 Benchmark 接近或超越 GPT-4o 与 DeepSeek-V3-0324；GLM-Z1-Air 主打"最快推理"档位；智谱开放平台文档同步上线 Air-250414、Flash-250414 等商用型号。
- **来源：** https://next.ithome.com/archiver/845/286.htm ；https://juejin.cn/post/7493174260497956864 ；https://docs.bigmodel.cn/cn/guide/models/text/glm-4

### 6. [一般] [芯片算力 / 政策监管] 英伟达宣布首次在美国本土制造 AI 超级计算机

- **关键细节：** 中文 AI 行业日报将此事列为本周重点动态；同期马斯克亦就"通用、纯 AI 全自动驾驶"发声，AI 制造与自动驾驶话题叠加。

### 7. [一般] [大模型发布] OpenAI 计划逐步下线 GPT-4.5 API

- **发生了什么：** 4 月 14 日，TechCrunch 报道 OpenAI 计划在 7 月 14 日前逐步关闭 API 端的 GPT-4.5 访问，原因是该模型推理成本过高，且新发布的 GPT-4.1 在多数任务上性能相当甚至更好、价格低得多；GPT-4.5 在 ChatGPT 端仍保留给部分订阅用户。
- **为什么重要：** 发布不到两个月即被"退役"，是"旗舰模型成本不可持续"的最直接证据，也确认了行业定价逻辑的变化：厂商不再为"最贵最强"保留长期接口，而是快速把流量导向性价比模型。
- **关键细节：** 微软 Azure 的模型目录同样将 gpt-4.5-preview 标注为 2025 年 7 月 14 日退役，推荐迁移到 GPT-4.1（2025-04-14 版本），与 OpenAI 口径一致。
- **来源：** https://ai-weekly.ai/newsletter-04-15-2025/ ；https://learn.microsoft.com/de-de/Azure/foundry/openai/concepts/retired-models

### 8. [一般] [政策监管] 欧盟数据保护委员会发布《人工智能隐私风险与缓解措施：大型语言模型》报告

- **发生了什么：** 据行业周刊汇总，欧盟数据保护委员会（EDPB）在本周发布《人工智能隐私风险与缓解措施：大型语言模型（LLM）》报告，提出一套覆盖 LLM 全生命周期的隐私风险清单与缓解措施，涉及训练数据合法性、记忆与输出中的个人信息、跨境传输与数据主体权利等。
- **为什么重要：** 欧盟监管重心正从"模型训练版权"扩展到"部署隐私"，该报告将成为欧洲企业采用 LLM 的合规参照，也可能影响各家 AI 公司面向欧盟市场的产品设计（数据驻留、遗忘机制等）。
- **关键细节：** 报告由 EDPB 专家团队编写，以"风险-缓解"框架组织；同期中文行业周刊评价本周"产品及技术更新迭代加快，政策支持不断强化"。
- **来源：** https://m.chyxx.com/news/1220362.html

## 三、本周行业变化总结

本周是"编程 Agent 商业化"的转折周：OpenAI 用 GPT-4.1（性价比 + 长上下文）与 o3/o4-mini（推理 + 工具链）完成模型层布局，再用开源 Codex CLI 把能力直接送到开发者终端，模型厂商与编程工具厂商的边界开始模糊。芯片侧则出现"镜像动作"：一边是 H20 对华出口被"无限期"许可证卡住，一边是英伟达宣布在美本土制造超算，台积电财报证明 AI 需求真实强劲——三者共同确认算力政治化与景气度并存。中国厂商抓住 Llama 4 信任危机的窗口，智谱以"开源 + 免费 + 高速"组合拳抢位。监管侧，欧盟把 LLM 隐私问题系统化、清单化，合规成本开始成为企业选型的硬指标。

## 四、本周趋势分析

1. **模型竞争从"分数"转向"每美元 token"。** GPT-4.1 三档定价与 GPT-4.5 的快速退役说明：能刷榜不等于能盈利，推理经济学成为模型设计的核心约束。
2. **编程 Agent 进入"终端原生"阶段。** Codex CLI 发布后，"命令行里的代理"将成标配形态，与 IDE 内代理（Copilot、Cursor）和云端异步代理形成三足格局；基准之外，真实仓库的工程化评测会更受重视。
3. **AI 供应链"双循环"加速。** H20 管制与美本土制造同周出现，意味着 AI 硬件将分别构建"中国链"与"非华链"两套体系，两地模型厂商的算力成本曲线将分化。
4. **开源窗口期争夺战。** Llama 4 风波后，DeepSeek、智谱、Qwen 等中国开源力量正在填补信任真空，"可复现 + 可商用 + 高速推理"成为开源新三件套。
5. **隐私合规成为 LLM 企业采购的显性门槛。** EDPB 报告把抽象的 GDPR 原则翻译成 LLM 场景的操作清单，预计将催生"合规评估"类工具与服务。

## 五、值得尝试的工具与工作流

1. **Codex CLI（开源）**：终端党可立即上手，用 o4-mini 驱动"读代码库、跑测试、提 PR"的循环；注意配置 API 用量上限以控制成本。
2. **GPT-4.1 nano/mini**：把现有 GPT-4o/4o-mini 调用迁移到 4.1 系列做 A/B，多数抽取、分类、代码补全场景可省钱 30% 以上；长文档分析用 1M 上下文窗口一次喂入。
3. **GLM-Z1-Rumination**：需要"深度思考 + 自主搜索"的调研类 Agent，可用其开源权重 + 智谱免费 API 快速搭建原型。
4. **GPT-4.5 迁移预案**：使用 GPT-4.5 API 的团队应在 7 月 14 日退役节点前完成向 GPT-4.1 的回归测试，重点核对指令遵循与输出格式差异。

## 六、下周值得关注的事项

1. **OpenAI Codex 系统的 API 开放节奏**：官方称 Codex 将向企业客户逐步开放，下周起可能有更多接入细节。
2. **英伟达对华政策与 H20 库存处理**：许可证审批口径、中国区订单调整将影响供应链预期，市场等待管理层进一步说明。
3. **国产开源跟进**：Llama 4 争议发酵下，下周或有更多国内厂商发布可复现评测与开源新品。
