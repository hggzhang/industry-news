## 一、本周核心结论

1. 本周是 2025 年下半年最重磅的"模型对决周"：谷歌 Gemini 3、OpenAI GPT-5.1 Pro 与 GPT-5.1-Codex-Max、xAI Grok 4.1 在同一周内先后发布，LMArena 榜单被反复改写。

## 二、本周重要事件

### 1. [重大] [大模型] 谷歌发布 Gemini 3，号称"全球最智能模型"并登顶各大基准
- **发生了什么：** 11 月 18 日，谷歌发布新一代旗舰模型 Gemini 3（Gemini 3 Pro 先行，面向 Gemini App 与 AI Pro/Ultra 订阅用户）。官方称其在几乎所有主流基准上显著超越 Gemini 2.5 Pro：以 1501 Elo 登顶 LMArena 文本总榜，Humanity's Last Exam 无工具得分 37.5%，GPQA Diamond 达 91.9%，SWE-bench Verified 76.2%，并在数学、代码与多模态（MMMU-Pro 81%）上全面刷新纪录。Gemini 3 主打"思考更深、更懂上下文"，支持生成式 UI（回答中动态生成图表、滑块、3D 可视化），一句话生成网站乃至简单开放世界游戏demo；其 Agent 长期规划能力在 Vending-Bench 2 排名第一。
- **为什么重要：** 这是谷歌自 2024 年落后以来第一次在"旗舰模型心智"上反超 OpenAI，且发布时点恰好卡在 GPT-5.1 之后、GPT-5.1 Pro 之前，直接重塑了企业选型格局。Gemini 3 的推理+代码+长程 Agent 组合，加上谷歌自有 TPU 的成本优势，意味着闭源旗舰市场的价格与性能曲线将由谷歌主导定义。
- **关键细节：** 发布日 11 月 18 日；LMArena 1501 Elo；GPQA Diamond 91.9%、HLE 37.5%（无工具）、SWE-bench Verified 76.2%；生成式 UI 与深度思考能力为产品级新特性；搜索、Chrome、Android、Workspace 全线接入。
- **来源：** https://blog.google/products/gemini/gemini-3/ ；https://9to5google.com/2025/11/18/gemini-3-launch/ ；https://news.qq.com/rain/a/20251119A009AE00

### 2. [重大] [大模型] OpenAI 发布 GPT-5.1 Pro 与 GPT-5.1-Codex-Max，正面回应 Gemini 3
- **发生了什么：** 11 月 20 日（周五），OpenAI 在 Gemini 3 发布仅两天后推出两款高端模型：GPT-5.1 Pro（面向 Pro/Enterprise 用户的最高能力版本，主打复杂科学、工程与长文档推理）与 GPT-5.1-Codex-Max（前沿代理编码模型，底层推理模型更新并针对软件工程、数学、研究等多元代理任务训练，强调在开发周期各阶段的速度与长任务可靠性，已在 Codex 上线）。券商周报将其概括为"AI 叙事更新"的关键节点，ChatGPT 周使用时长环比增长约 28.8%。
- **为什么重要：** OpenAI 用"一周三连发"（5.1、5.1 Pro、5.1 Codex-Max）证明其版本迭代已武器化：以高频小版本压制对手的发布窗口。Codex-Max 把编码 Agent 从"模型能力"升级为"带速度优化的产品线"，说明编程 Agent 是当前变现最快、竞争最烈的主战场。
- **关键细节：** GPT-5.1 Pro 面向高难推理场景，定价高于普通 5.1；Codex-Max 为 Codex 全系默认前沿模型，官方强调长周期代理任务与多语言工程库适配；发布时间 11 月 20 日，距 Gemini 3 发布仅 48 小时。

### 3. [重大] [芯片算力] 微软、英伟达与 Anthropic 宣布三重战略合作，Claude 上架 Azure
- **发生了什么：** 11 月 18 日，微软、英伟达与 Anthropic 同日宣布新的战略合作：Anthropic 将在微软 Azure 上（由英伟达系统驱动）扩展其快速增长的 Claude 模型服务，并承诺采购 300 亿美元的 Azure 算力、锁定最高 1 吉瓦的额外算力容量；英伟达与 Anthropic 首次建立深度技术 partnership，英伟达对 Anthropic 进行大规模战略投资（媒体报道规模最高达 100 亿美元级，含微软投资合计约 150 亿美元口径）；同日 Claude Sonnet 4.5、Opus 4.1、Haiku 4.5 进入 Microsoft Foundry 公测，Azure 成为唯一同时提供 OpenAI 与 Anthropic 前沿模型的云平台。
- **为什么重要：** 这笔交易把"微软只属于 OpenAI"的旧格局彻底改写：微软用 Anthropic 对冲 OpenAI 依赖，英伟达用投资锁定旗舰客户，Anthropic 获得第三家超大云供应商。前沿实验室与芯片/云厂的交叉持股与长约绑定，正在形成"算力-模型-分发"三位一体的联盟化竞争结构。
- **关键细节：** Anthropic 承诺 300 亿美元 Azure 算力采购、最高 1 吉瓦新增容量；Claude 在 Microsoft Foundry 公测并接入 365 Copilot 的 Researcher 智能体与 Excel Agent 模式；交易与上周谷歌 TPU 大单叠加，Anthropic 一周内锁定的算力横跨三大云。

### 8. [一般] [AIGC 视频] 腾讯开源 HunyuanVideo 1.5：8.3B 参数、消费级显卡可跑
- **发生了什么：** 11 月 21 日，腾讯混元团队发布并开源轻量级视频生成模型 HunyuanVideo 1.5：基于统一 Diffusion Transformer 架构、仅 8.3B 参数，支持文生视频与图生视频，可生成 5 至 10 秒高清视频，官方称以顶尖开源质量与极低推理门槛为卖点，可在消费级显卡流畅运行；技术报告同步上传 arXiv（2511.18870）。腾讯元宝 App 同日上线该模型的生成视频能力。
- **为什么重要：** 视频生成的"质量-成本"曲线被开源阵营再次压低：8.3B 即可逼近商用效果，意味着中小团队自建视频管线的门槛大幅下降，对 Runway、Pika 等闭源 API 厂商形成定价压力，也强化了腾讯"全模态开源"的生态路线。
- **关键细节：** 参数 8.3B；DiT 统一架构、两阶段高保真合成；支持 480p 至 720p+ 区间生成与 5 至 10 秒时长；权重在 Hugging Face/ModelScope 开源，商用友好；元宝同步接入。
- **来源：** https://hunyuan.tencent.com/video/en?tabIndex=0 ；https://view.inews.qq.com/a/20251121A03RFX00 ；https://arxiv.org/pdf/2511.18870

### 9. [一般] [AI 编程] Codex/GPT-5.1-Codex-Max 与 Cursor 高估值共振，编程 Agent 进入军备赛
- **发生了什么：** 本周 OpenAI 发布 GPT-5.1-Codex-Max 后，编程 Agent 赛道形成"模型厂+编辑器厂"双线竞赛：上周刚完成 23 亿美元 D 轮（估值 293 亿美元）的 Cursor 继续加码自研 Composer 与多 Agent 编辑器，OpenAI 则以 Codex-Max 抢占"官方编码模型"心智；券商周报显示 ChatGPT 周使用时长环比增长 28.83%，编程与代理任务为主要驱动。

- **关键细节：** Codex-Max 强调开发周期各阶段的速度优化与长任务稳定性；Cursor 2.0（10 月 29 日）已内置多 Agent 管理界面；两家路线差异在于"编辑器内自研小模型"与"云端前沿大模型"。

## 三、本周行业变化总结

本周的行业重心从"基础设施承诺"切换回"旗舰模型对决"，但结构已完全不同：发布节奏以天计（17 日 Grok 4.1、18 日 Gemini 3 与 Anthropic 联盟、19 日英伟达财报与 Grok 4.1 Fast、20 日 GPT-5.1 Pro/Codex-Max），基准榜单一周内多次易主。另一个关键变化是"联盟重组"：微软同时站在 OpenAI 与 Anthropic 两边，英伟达同时投资客户与对手客户，谷歌用 TPU 绑定 Anthropic 又用 Gemini 与 OpenAI 抢用户。中国侧，阿里以集团之力下场 C 端入口战，腾讯以开源视频模型卡位轻量生态，中美两条战线都在从单点模型转向"生态系统战"。

## 四、本周趋势分析

1. 旗舰模型进入"48 小时响应"竞争：OpenAI 在 Gemini 3 发布两天内即推 Pro 与 Codex-Max，发布窗口本身成为武器，单纯憋大招的策略失效。
2. 交叉投资成为算力新常态：芯片商（英伟达）、云厂（微软/谷歌/AWS）与实验室（OpenAI/Anthropic）互相持股、互相长约，竞争单位从公司变成联盟。
3. 推理效率叙事压过参数叙事：GB300 每兆瓦 10 倍吞吐、HunyuanVideo 1.5 的 8.3B 参数、Grok 4.1 Fast 的低成本 API，本周几乎所有产品发布都以"单位成本能力"为核心卖点。
4. Agent 基建标准化提速：Foundry IQ、Hosted Agents、Agent 365、Codex-Max 长任务能力共同指向"可托管、可审计、可计费"的企业 Agent 基础设施层，2026 年该层将决定云厂商 AI 收入的分配。

## 五、值得尝试的工具与工作流

- Gemini 3 Pro（Gemini App / AI Pro）：重点体验生成式 UI 与长文档推理，适合把现有 ChatGPT 工作流做一次盲测对比；官方介绍见 https://blog.google/products/gemini/gemini-3/ 。

- HunyuanVideo 1.5：消费级显卡即可自建文生视频/图生视频原型，适合短视频素材管线的低成本试验，权重见 https://modelscope.cn/models/Tencent-Hunyuan/HunyuanVideo-1.5 。
- 千问 App：体验"AI+生态办事"的中文场景闭环（购物、出行、支付接入进度值得跟踪）。
