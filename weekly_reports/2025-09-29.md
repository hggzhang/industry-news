## 二、本周重要事件

### 1. [重大] [AIGC视频] OpenAI 发布旗舰音视频模型 Sora 2 与邀请制社交应用 Sora

- **发生了什么：** 当地时间 9 月 30 日，OpenAI 正式发布新一代视频生成模型 Sora 2，并同步上线社交应用 Sora（iOS 邀请制，网页版 sora.com 先行开放）。官方发布说明称 Sora 2 是旗舰音视频生成模型，可生成带同步对话与音效的视频，物理与动态表现显著增强；ChatGPT Pro 用户可额外使用实验性更高画质的 Sora 2 Pro，官方同时宣布计划推出 Sora 2 API，并保留 Sora 1 Turbo。App 采用类似 TikTok 与 Instagram Reels 的竖屏算法推荐信息流，其中每一条视频都由 AI 模型生成而非相机拍摄，上线后以邀请制快速扩张。新华网 10 月 1 日发布的全球人工智能盘点报道确认了这次发布，将其列为当月最重要的技术事件之一。
- **为什么重要：** 这是 OpenAI 继 ChatGPT 之后第一次把前沿模型直接包装成大众消费社交产品，"信息流内容全部由生成模型产出"若被验证，将同时冲击短视频平台的供给逻辑与内容审核体系，也把谷歌 Veo 系列、快手可灵、Runway 等视频模型拖入"技术+分发"的双重正面战。对行业而言，Sora 2 把"音画同步生成"变成旗舰能力门槛，视频模型的技术竞赛正式与消费级产品竞赛合流。
- **关键细节：** 发布节奏为网页版先行、iOS 邀请制跟进，Android 版尚未开放；Sora 2 Pro 仅限 ChatGPT Pro 订阅用户；官方明确将支持"客串"式真人形象合入与商业使用授权，同步配套显式水印与 C2PA 类内容凭证等安全措施；API 发布列入计划但尚未开放。
- **来源：** https://openai.com/index/sora-2/ ；http://www.news.cn/tech/20251001/2a2c3bc60be944b190da251ace2fc45f/c.html ；https://www.aiwiki.ai/wiki/sora_app

### 2. [重大] [开源模型] DeepSeek-V3.2-Exp 发布：首推 DSA 稀疏注意力，API 降价超 50%

- **发生了什么：** 9 月 29 日，深度求索（DeepSeek）正式发布公告，推出实验性模型 DeepSeek-V3.2-Exp。核心创新是首次引入 DeepSeek 稀疏注意力机制（DeepSeek Sparse Attention，DSA），在长上下文场景下显著降低计算与显存开销，官方称该机制在保持效果的前提下大幅提升了训练与推理效率。公告同时宣布 API 价格下调：在相同档位下价格降幅超过 50%，并强调新架构带来的成本优势将进一步传导至推理服务。模型权重同步在 Hugging Face 与魔搭社区开源。
- **为什么重要：** 长上下文的二次方成本是智能体、代码库检索与文档批量处理等场景的最大经济瓶颈，DSA 把"稀疏注意力"从论文方案变成旗舰模型的量产实现，为全行业提供了可复现的降本路线。DeepSeek 延续"开源+降价"的组合拳，直接对 OpenAI、Anthropic、谷歌的 API 定价体系施压，也巩固了中国开源模型在全球开发者生态中的话语权；结合此前 R1 登上《自然》封面，DeepSeek 已成为推理效率之争的规则制定者之一。
- **关键细节：** 官方公告标题即突出"DSA 稀疏注意力"与"价格下调"两大卖点；降价幅度超过 50% 适用于其 API 主要档位；模型以实验版（Exp）名义发布，意味着后续仍有正式版迭代；开源同步覆盖 Hugging Face 与 ModelScope 双平台，国内外社区可在数日内完成部署验证。
- **来源：** https://api-docs.deepseek.com/zh-cn/news/news250929 ；https://www.deepseek.com/en/news/

### 3. [重大] [大模型发布] Anthropic 发布 Claude Sonnet 4.5：编程与计算机操作双料 SOTA

- **发生了什么：** 9 月 29 日，Anthropic 发布 Claude Sonnet 4.5，官方称其为"全球最好的编程模型"、构建复杂智能体最强的模型，也是计算机操作能力最好的模型：在 SWE-bench Verified 上达到最先进水平，OSWorld 真实电脑任务基准得分从四个月前 Sonnet 4 的 42.2% 跃升至 61.4%，官方称实测可在复杂多步任务上保持超过 30 小时专注。定价与 Sonnet 4 持平，为每百万输入 token 3 美元、输出 15 美元，发布当日即在全球可用。Cursor、Devin、Canva、Figma、Replit 等厂商在官方博客给出实测评价，Devin 方面称规划性能提升 18%、端到端评测提升 12%。
- **为什么重要：** 在 OpenAI 上周发布 GPT-5-Codex、可灵与 Sora 相继更新的密集窗口期，Anthropic 用"中端价格、旗舰能力"的定位把编程智能体竞赛推向"长时程自主执行"的新维度：30 小时级专注意味着智能体可以独立承担过去需要数人日的工程任务。同时，官方强调这是"对齐度最高的前沿模型"，系统卡首次引入机制可解释性测试，并部署 ASL-3 安全等级与 CBRN 分类器，为前沿模型的发布安全标准提供了新的行业参照。
- **关键细节：** OSWorld 61.4% 领先所有公开模型；SWE-bench Verified 官方宣称 SOTA；价格不变策略使其相对 GPT-5 系列具备明显性价比；系统卡披露自动行为审计显示谄媚、欺骗、权力寻求等失准行为显著下降，并加强了针对提示注入攻击的防御；同步推出"Imagine with Claude"临时研究预览。
- **来源：** https://www.anthropic.com/news/claude-sonnet-4-5 ；https://github.blog/changelog/2025-09-29-anthropic-claude-sonnet-4-5-is-in-public-preview-for-github-copilot/

### 4. [重要] [政策监管] 加州签署 SB 53：美国首部前沿 AI 透明度州法生效

- **发生了什么：** 9 月 29 日，加州州长纽森在萨克拉门托签署参议院第 53 号法案《前沿人工智能透明度法案》（TFAIA，由旧金山民主党参议员 Scott Wiener 提出）。法案要求前沿 AI 开发者公开披露安全与透明度框架、向州政府报告特定重大安全事件，并保护披露严重风险的举报人；州司法部保留执法权。纽森在签署声明中表示，该法将建立州级监督机制，使加州有能力监测、评估并响应先进 AI 系统的重大安全事件，同时继续为创新留出空间。律所 Fisher Phillips 的合规解读指出，SB 53 相比去年被否决的 AB 303 大幅收窄了义务边界，是立法与产业博弈后的折中版本。
- **为什么重要：** 这是美国联邦层面（白宫 OSTP 正推进清理监管障碍的意见征集）选择做减法的同时，州级监管完成的实质性立法突破。加州聚集了全美最多的前沿实验室，SB 53 事实上将成为全国性的合规基线，其"披露安全框架+事故报告+举报人保护"三件套预计被其他州快速复制，也将反向影响企业系统卡与安全报告的披露深度。对模型厂商而言，事故定义、披露粒度与商业秘密边界的规则制定过程，将是未来一年美国 AI 合规的核心变量。
- **关键细节：** 法案于 2025 年 9 月 29 日签署生效，具体实施细则与指南由州相关部门后续发布；适用对象为算力与收入达到阈值的前沿模型开发者；被业界普遍视为全美首部针对前沿大模型的透明度法律；同期签署的还有涉及生物识别与 AI 生成内容的多项配套法案。
- **来源：** https://www.gov.ca.gov/2025/09/29/governor-newsom-signs-sb-53-advancing-californias-world-leading-artificial-intelligence-industry/?categoryid=2826733 ；https://www.fisherphillips.com/print/v2/content/43018/california-lawmakers-pass-landmark-ai-transparency-law-for-frontier-models.pdf ；https://www.californiacompute.org/documents/SB-53-Signing-Message/

### 5. [重要] [AI编程工具] GitHub Copilot 上线 Claude Sonnet 4.5 公开预览

- **发生了什么：** 9 月 29 日，GitHub 官方 changelog 宣布 Anthropic Claude Sonnet 4.5 以公开预览形式进入 GitHub Copilot，开发者可在 Copilot 的智能体编程体验中选择该模型。GitHub 首席产品官 Mario Rodriguez 同步表态，称初步评估显示 Sonnet 4.5 在多步推理与代码理解上显著改进，能让 Copilot 的智能体体验更好地处理跨代码库的复杂任务。
- **为什么重要：** GitHub Copilot 长期以 OpenAI 模型为默认底座，本次在发布当日即接入 Anthropic 旗舰编程模型，确认了"分发渠道多模型化"已成定局：对 Anthropic 而言，这是触达数千万开发者最直接的入口；对 OpenAI 而言，GPT-5-Codex 在自家 Codex 之外面临的渠道竞争加剧。结合上周 Copilot SWE 专用模型与 Copilot CLI 公开预览，GitHub 正在把自己重塑为"模型市场+智能体工作流"的中立平台，默认模型的推荐位将成为 AI 编程竞争的隐形战场。
- **关键细节：** 公开预览面向 Copilot 订阅用户逐步开放；接入时点与 Anthropic 发布同日，显示双方预集成周期极短；GitHub 高管的评测表态（多步推理、跨代码库任务）与 Anthropic 官方案例中"30 小时长任务"卖点一致。
- **来源：** https://github.blog/changelog/2025-09-29-anthropic-claude-sonnet-4-5-is-in-public-preview-for-github-copilot/ ；https://www.anthropic.com/news/claude-sonnet-4-5

### 6. [一般] [智能体基础设施] Anthropic 开放 Claude Agent SDK，智能体中间件进入标准化竞争

- **发生了什么：** 9 月 29 日，随 Sonnet 4.5 发布，Anthropic 将驱动 Claude Code 的内部基础设施打包为 Claude Agent SDK 向开发者开放，官方称其解决了智能体的三大难题：长任务记忆管理、平衡自主权与用户控制的权限系统、多个子智能体围绕共同目标的协调。同批更新还包括：Claude Code 新增检查点（checkpoint）一键回滚、全新终端界面、原生 VS Code 扩展上线，以及 Claude API 新增上下文编辑与记忆工具，让智能体可以运行更久、处理更复杂的任务。
- **为什么重要：** 智能体开发正在从"用通用编排框架拼轮子"进入"复用前沿实验室工程栈"的阶段。Agent SDK 把 Claude Code 验证过的循环（规划、执行、测试、回滚）变成标准件，直接对标 OpenAI 的 Agents SDK 与谷歌的 ADK，三方围绕"智能体运行时"的事实标准之争已经展开。对应用开发者，选择哪套 SDK 意味着选择哪条模型与工具生态，迁移成本将在未来 12 个月快速累积。
- **关键细节：** Anthropic 官方称已花六个月以上时间持续迭代 Claude Code 后才将底层开放；检查点是官方口径中"用户最期待的功能之一"；上下文编辑与记忆工具面向 API 层，配合 30 小时级长任务能力形成完整的长程智能体方案。
- **来源：** https://www.anthropic.com/news/claude-sonnet-4-5 ；https://anthropic.com/engineering/building-agents-with-the-claude-agent-sdk

## 三、本周行业变化总结

本周是 9 月超级发布月的收官周，竞争格局出现清晰的三层分化：模型层，Anthropic 与 OpenAI 在编程与智能体能力上贴身肉搏，DeepSeek 则另辟蹊径用稀疏注意力和降价打穿成本曲线；产品层，Sora 2 把生成能力直接封装成消费级社交应用，前沿实验室第一次以"平台公司"姿态进入内容分发市场；制度层，SB 53 在美国州级落地，与联邦放松路线并行，企业合规重心被迫转向"按辖区拆分披露策略"。工具层同样密集：Agent SDK、Copilot 多模型接入、检查点与记忆工具，智能体的"运行时基础设施"在一周内集中供给。整体看，行业叙事已从"谁的基准分高"转向"谁能把能力变成可持续运行的产品与可审计的制度"。

## 四、本周趋势分析

1. **长时程自主性成为旗舰模型的核心卖点。** Sonnet 4.5 的"30 小时专注"与 GPT-5-Codex 的数小时级任务在同一周出现，说明评测单位正从单次回答质量转向任务时长与完成率，配套的权限、检查点、回滚机制会成为智能体产品的标配安全层。
2. **注意力机制的架构级降本开始主导定价。** DeepSeek 用 DSA 支撑 50% 以上降价，意味着下一轮 API 价格战的主武器不是补贴而是架构效率；无法跟进稀疏注意力或同等工程优化的厂商，将在智能体这类高 token 消耗场景中失去成本竞争力。
3. **前沿实验室"产品化"与"平台化"并进。** OpenAI 用 Sora App 进军社交分发，Anthropic 用 Agent SDK 沉淀开发者平台，两家都在把模型能力转化为渠道与生态控制力；纯模型 API 生意的利润空间预计被上下游同时挤压。
4. **美国监管进入"州法先行、联邦观望"的双轨期。** SB 53 的披露与事故报告义务将塑造前沿实验室的安全文档标准，并与欧盟《人工智能法案》的通用义务、中国的框架 2.0 与标识办法共同构成三大合规体系，跨国部署的合规映射成本显著上升。
5. **AIGC 视频进入"社交分发"竞争维度。** Sora App 的算法信息流把视频模型的竞争从生成质量扩展到推荐与社区运营，可灵、Veo 等对手需要同时回答"模型怎么更强"与"内容给谁看"两个问题，水印与内容凭证将成为平台治理的强制基础设施。

## 五、值得尝试的工具与工作流

- **Claude Sonnet 4.5 + Agent SDK：** 有长周期自动化任务（代码库迁移、批量重构、运营脚本）的团队，可用 Agent SDK 搭建带检查点回滚的智能体原型，重点验证 30 小时级任务在自家环境中的完成率与失控风险。
- **DeepSeek-V3.2-Exp API：** 长上下文场景（海量文档检索、多仓库代码问答）可立即切换测试，对比降价 50% 叠加 DSA 效率后的真实账单，同时评估开源权重私有化部署与托管 API 的成本平衡点。
- **GitHub Copilot 的模型切换：** 已订阅 Copilot 的团队可在智能体任务中手动指定 Sonnet 4.5 与 GPT-5-Codex 做同任务 A/B，记录跨代码库任务的成功率与 token 消耗，为团队默认模型选型积累数据。
- **Sora App（海外运营场景）：** 面向北美用户的品牌与内容团队，可申请邀请码观察 AI 原生信息流的内容形态与用户接受度，提前评估"生成内容社交"对短视频投放与素材生产的替代效应。
- **SB 53 合规自查：** 在美国市场运营前沿模型或智能体产品的团队，应把"安全框架公开披露、重大事故报告、举报人保护"三项义务映射到现有安全文档流程，避免细则出台后被动补课。
